# 🧭 ASSIGNMENT 1 — HTML MULTI-PAGE SITE

**Week 1 — “Something Exists”**

---

## 🔹 Context

You are beginning your work as a web developer by creating something that exists and can be accessed in a browser.

This week focuses on **structure only**.
You are not expected to style your pages or add behavior yet.

The goal is to understand how content is organized and connected.

---

## 🔹 Objective

Create a simple multi-page website using HTML that demonstrates:

* clear structure
* logical organization
* working navigation between pages

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Create the initial version of your website.

---

### 🔹 Requirements

* Create **at least 3 HTML pages**

  * Example: Home, About, Topic page

* Each page must include:

  * headings (`h1`, `h2`, etc.)
  * paragraphs
  * at least one list (ordered or unordered)

* Add **navigation links** between all pages

* Use **basic semantic structure** where possible

---

### 🔹 Focus

* Getting something working
* Connecting pages correctly
* Understanding structure

---

### 🔹 Expectation

This version will likely be imperfect.
That is expected.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* How web pages are structured using HTML
* The role of semantic elements in organizing content
* How pages are connected through links and navigation
* Common structural mistakes and how to recognize them
* Thinking of a web page as a document with meaning, not just content

---

# 🔧 ITERATION 2 — REFINE (Thursday Lab)

### 🔹 Task

Improve your existing site based on what you learned.

---

### 🔹 Requirements

* Fix any broken or incorrect links
* Improve heading structure (logical hierarchy)
* Clean up content organization
* Ensure each page is clearly readable and structured

---

### 🔹 Focus

* Clarity
* correctness
* organization

---

# 📦 FINAL SUBMISSION

Submit your **final version** of your website.

---

### 🔹 Submission Requirements

* All HTML files
* Organized in a single folder
* File names are clear and consistent (e.g., `index.html`, `about.html`)

---

# 🧠 REFLECTION (Required — Short)

In 2–3 sentences, answer:

> What did you improve between your first and second version, and why?
