# Week 13 Success Notes - Security And Reliability

This package shows one acceptable successful version for Assignment 13. It continues `Study Sprint` by handling user input carefully and explaining the reliability/security choices.

## Files Included

- `index.html`
- `styles.css`
- `script.js`
- `reliability_note.md`

## What This Version Demonstrates

- input validation
- safe text output with `textContent`
- clear feedback for empty input
- no claim of real authentication
- a short reliability note that explains the issue and fix

## Instructor Demo Use

Show this at the beginning of Week 14 after Assignment 13 has been submitted.

Recommended rhythm:

1. Try empty input.
2. Try normal text.
3. Try text that looks like HTML.
4. Show that the output remains text.
5. Open the reliability note and connect the code to the explanation.

## Revision Recovery Connection

Students revising Assignment 13 should identify a real risk or reliability issue and explain the protection they added.

## Tradeoffs

This is browser-security awareness, not complete application security. There is no backend, real login, token, or account protection.
