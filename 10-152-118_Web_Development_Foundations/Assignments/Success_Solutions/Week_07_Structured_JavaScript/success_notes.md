# Week 07 Success Notes - Structured JavaScript

This package shows one acceptable successful version for Assignment 7. It continues the `Study Sprint` planner and refactors the JavaScript into clearer functions.

## Files Included

- `index.html`
- `tips.html`
- `schedule.html`
- `styles.css`
- `script.js`

## What This Version Demonstrates

- JavaScript organized into several named functions
- meaningful variable names
- reduced repeated output logic
- separate responsibilities for reading input, validating input, deciding the plan, and updating the page
- behavior preserved after refactoring

## Instructor Demo Use

Show this at the beginning of Week 8 after Assignment 7 has been submitted.

Recommended rhythm:

1. Run the Week 6 version briefly.
2. Open this Week 7 version and verify the same behavior still works.
3. Open `script.js` and identify each function's responsibility.
4. Emphasize that refactoring made the code easier to read without changing the basic feature.

## Revision Recovery Connection

Students revising Assignment 7 should focus on making working JavaScript clearer. They should be able to explain what each function does and why the new structure is easier to maintain.

## Tradeoffs

This version uses plain functions and simple DOM updates. It avoids advanced patterns so the structure remains beginner-readable.
