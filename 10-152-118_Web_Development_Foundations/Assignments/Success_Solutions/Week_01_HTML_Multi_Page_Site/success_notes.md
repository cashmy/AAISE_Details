# Week 01 Success Notes - HTML Multi-Page Site

This package shows one acceptable successful version for Assignment 1. It is not the only possible answer because students may choose different site topics, pages, and content.

## Chosen Site

`Study Sprint`

This sample site helps students organize study habits, resources, and weekly planning.

The topic is intentionally different from the lecture demo so the success solution shows transfer, not a copy of the demo.

## Files Included

- `index.html`
- `tips.html`
- `schedule.html`

## What This Version Demonstrates

- at least three HTML pages
- clear page titles and headings
- paragraphs on each page
- lists on each page
- navigation between all pages
- basic semantic structure with `header`, `nav`, `main`, `section`, and `footer`
- structure-first thinking with no CSS or JavaScript

## Instructor Demo Use

Show this at the beginning of Week 2 after Assignment 1 has been submitted.

Recommended rhythm:

1. Open the site in a browser and click through the navigation.
2. Open one file and point out the structure.
3. Compare the successful result to the Assignment 1 requirements.
4. Emphasize that this is one acceptable path, not the only correct site.

## Revision Recovery Connection

Students revising Assignment 1 may use this example to understand what a complete result can look like.

Their revision should still use their own topic and content unless you explicitly approve a different plan.

Useful revision note pattern:

```text
What I changed:

Why I changed it:

How I verified the improvement:
```

## Tradeoffs

This version keeps the content simple and readable. It does not include styling yet, because Assignment 1 is focused on HTML structure.
