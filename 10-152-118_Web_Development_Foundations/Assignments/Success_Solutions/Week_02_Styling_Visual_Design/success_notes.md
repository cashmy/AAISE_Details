# Week 02 Success Notes - Styling And Visual Design

This package shows one acceptable successful version for Assignment 2. It continues the `Study Sprint` site from Week 1 and adds a CSS layer.

## Files Included

- `index.html`
- `tips.html`
- `schedule.html`
- `styles.css`

## What This Version Demonstrates

- one external CSS file
- the same stylesheet linked from all pages
- readable typography and line length
- consistent colors
- spacing with margin and padding
- styled navigation
- class-based styles
- visual consistency without changing the site topic

## Instructor Demo Use

Show this at the beginning of Week 3 after Assignment 2 has been submitted.

Recommended rhythm:

1. Open the Week 1 HTML-only version briefly.
2. Open this Week 2 styled version.
3. Point out that the content is mostly the same, but the experience changed.
4. Open `styles.css` and identify the shared rules.
5. Show how one stylesheet supports all three pages.

## Revision Recovery Connection

Students revising Assignment 2 should focus on improving their own CSS layer:

- link one external stylesheet correctly
- improve readability
- make spacing intentional
- keep navigation consistent
- use at least one class-based style

## Tradeoffs

This version is intentionally restrained. It does not attempt advanced layout yet because Week 3 handles layout and responsiveness more directly.
