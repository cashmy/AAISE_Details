# 🧭 ASSIGNMENT 2 — STYLING & VISUAL DESIGN

**Week 2 — “I Can Control Appearance”**

---

## 🔹 Context

Last week, you created the structure of your website using HTML.

This week, you will control how your site **looks and feels** using CSS.

You are not rebuilding your site—you are **adding a new layer**.

---

## 🔹 Objective

Apply CSS to your existing multi-page website to improve:

* readability
* visual consistency
* layout and spacing

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Add basic CSS styling to your existing website.

---

### 🔹 Requirements

* Create a **single external CSS file**

* Link it to all pages

* Apply styling to:

  * text (font, size, color)
  * background colors
  * spacing (margin and/or padding)

* Ensure:

  * text is readable
  * layout is not cluttered

---

### 🔹 Focus

* Connecting CSS to HTML
* Making visible changes
* Understanding how styles apply

---

### 🔹 Expectation

Your styling may be simple or inconsistent at first.
That is expected.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* How CSS controls appearance and visual consistency
* The relationship between structure (HTML) and style (CSS)
* Basic layout principles: spacing, readability, and hierarchy
* The box model (margin, padding, border) as a way to control space
* Common styling issues that affect usability

---

# 🔧 ITERATION 2 — REFINE (Thursday Lab)

### 🔹 Task

Improve your styling for clarity and consistency.

---

### 🔹 Requirements

* Ensure **consistent styling across all pages**

* Improve:

  * spacing (avoid crowding or excessive gaps)
  * text hierarchy (headings vs body text)
  * color choices (readable contrast)

* Apply:

  * at least one **class-based style**
  * consistent navigation styling

---

### 🔹 Focus

* Intentional design
* consistency
* usability

---

# 📦 FINAL SUBMISSION

Submit your updated website including:

* HTML files
* CSS file

---

### 🔹 Submission Requirements

* CSS must be in a **separate file**
* File structure must remain organized
* All pages must render correctly

---

# 🧠 REFLECTION (Required — Short)

> What changes did you make to improve the design, and how did those changes affect readability or usability?

# 🔥 Instructor Notes (For You)

This assignment establishes:

* CSS as a **layer, not a rewrite**
* importance of **consistency across pages**
* early **design judgment (not just mechanics)**

Watch for:

* inline styles creeping in
* inconsistent spacing
* “random color usage”
