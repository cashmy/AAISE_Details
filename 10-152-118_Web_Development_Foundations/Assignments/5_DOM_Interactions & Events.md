# 🧭 ASSIGNMENT 5 — DOM INTERACTION & EVENTS

**Week 5 — “Now It Connects”**

---

## 🔹 Context

Last week, you learned how to write JavaScript programs.

This week, you will connect that logic to your web pages.

You will make your site respond to user actions.

---

## 🔹 Objective

Use JavaScript to interact with your HTML pages by:

* selecting elements
* responding to user events
* updating content dynamically

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Add basic interactivity to your existing website.

---

### 🔹 Requirements

* Link a **JavaScript file** to at least one page

* Implement at least **one event-driven interaction**, such as:

  * button click
  * link interaction
  * input change

* Your interaction must:

  * update content on the page
  * or change a visible element

---

### 🔹 Examples (for guidance, not required)

* button that changes text
* toggle visibility of a section
* display a message based on input

---

### 🔹 Focus

* connecting JavaScript to HTML
* triggering behavior from user actions
* seeing immediate feedback

---

### 🔹 Expectation

This is your first full connection between layers.

It may feel confusing at first.

That is normal.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* How JavaScript selects and interacts with HTML elements
* Events as triggers for behavior (click, input, etc.)
* The relationship between user actions and program execution
* Common issues when connecting JavaScript to the DOM
* Thinking of the page as something that can change over time

---
