# 📘 HTML, CSS & JavaScript — Course Architecture (CAM-01)

### *16 Weeks | Layered Accumulation | Human-First → AI Later*

---

# 🔹 PHASE STRUCTURE

| Phase   | Weeks | Focus                          |
| ------- | ----- | ------------------------------ |
| Phase 1 | 1–2   | HTML + Basic CSS (Accelerated) |
| Phase 2 | 3–6   | CSS Depth + Layout             |
| Phase 3 | 7–9   | UX / Design Awareness          |
| Phase 4 | 10–12 | JavaScript (Behavior + Logic)  |
| Phase 5 | 13–16 | Integration + AI               |

---

# 🔹 WEEKLY LEARNING MODEL

Each week includes:

* **In-Class (Mon/Tue/Thu):**

  * Guided build
  * Debugging
  * Coaching

* **Video Lecture:**

  * Introduces new concepts

* **Homework:**

  * Reinforcement + extension
