# Demo Notes - Monday JSON Shape

**Related Assignment:** Assignment 10 - Data & APIs  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Show students how to read a JSON-like object before adding `fetch()` and timing.

## Delivery Mode

Type the object and selected field access live. Do not dump the whole object first; model choosing specific values.

## Concept Shown

- objects have named properties
- arrays use index positions
- data shape determines how code reads values
- displaying selected fields is clearer than dumping raw data

## Walkthrough

1. Type the `studyResource` object.
2. Read properties with dot notation.
3. Read the first tag with bracket notation.
4. Display selected values on the page.
5. Ask what would break if the property name changed.

## Misconceptions To Watch

- Students may try to display raw JSON directly.
- Students may confuse an array index with an object property.
- Students may assume all data has the same shape.

## Wednesday Bridge

The Wednesday demo retrieves JSON from a file with `fetch()` and turns an array of objects into visible page content.
