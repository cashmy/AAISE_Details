# Demo Notes - Monday Basic Form Submit

**Related Assignment:** Assignment 15 - Forms & Input Systems  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 12-15 minutes

## Purpose

Show form submission, `preventDefault()`, input reading, validation, and feedback before adding simulated login behavior.

## Delivery Mode

Build the submit handler live. Let the page reload once before adding `preventDefault()` so the need for it is visible.

## Concept Shown

- forms submit by default
- `preventDefault()` keeps the page from reloading
- form inputs provide structured user data
- validation and feedback improve reliability

## Walkthrough

1. Submit before JavaScript and observe the default behavior.
2. Add the submit event listener.
3. Add `event.preventDefault()`.
4. Read the input values.
5. Add validation and a success message.
