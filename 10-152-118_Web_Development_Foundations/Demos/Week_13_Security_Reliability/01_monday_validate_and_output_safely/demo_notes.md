# Demo Notes - Monday Validate And Output Safely

**Related Assignment:** Assignment 13 - Security & Reliability  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Introduce reliability and safety through a simple rule: user input should be checked and displayed safely.

## Delivery Mode

Build the validation branch and `textContent` output live. Keep the tone practical: this is a safer habit, not a complete security system.

## Concept Shown

- user input should not be blindly trusted
- empty input needs clear feedback
- `textContent` displays text safely for beginner projects
- reliability and security start with small habits

## Walkthrough

1. Type the selectors.
2. Read and trim the input value.
3. Add the empty-input branch.
4. Display the note with `textContent`.
5. Explain that this is safer than injecting raw HTML.
