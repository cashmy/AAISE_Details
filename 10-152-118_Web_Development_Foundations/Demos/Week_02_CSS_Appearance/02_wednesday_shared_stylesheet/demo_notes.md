# Demo Notes - Wednesday Shared Stylesheet

**Related Assignment:** Assignment 2 - Styling & Visual Design  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 12-18 minutes

## Purpose

Deepen Monday's first styling demo by applying one shared stylesheet across multiple pages. The core idea is consistency: one CSS file can guide the appearance of a small site.

## Delivery Mode

Build from the Week 1 multi-page structure. Type the stylesheet link on one page first, verify it, then copy the same link to the second page to show intentional reuse.

## Walkthrough

1. Briefly recall the Monday first-styles demo.
2. Add or inspect `link rel="stylesheet"` on `index.html`, save, and refresh.
3. Copy the stylesheet link to `about.html`, save, and refresh.
4. Type or paste class names such as `.site-header`, `.nav-list`, and `.page`.
5. Add shared CSS rules in small groups.
6. Change one CSS value and show that the shared design can update consistently.

## Misconceptions To Watch

- Students may think each page needs separate CSS.
- Students may overuse inline styles.
- Students may change HTML structure just to create visual spacing.

## Lab Bridge

Students should style their Week 1 site with readable typography, spacing, color, and consistent navigation.

## Optional Extension

Temporarily remove the stylesheet link to show the same HTML without CSS.
