# Demo Notes - Monday First Styles

**Related Assignment:** Assignment 2 - Styling & Visual Design  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 8-12 minutes

## Purpose

Show the first clear separation between HTML content and CSS appearance.

## Delivery Mode

Build the stylesheet live. Type the selectors and a few key declarations by hand so students see CSS as rules they write, not a finished skin that appears all at once.

## Concept Shown

- the stylesheet link connects HTML to CSS
- selectors choose elements
- CSS declarations change color, font, spacing, and readable line length
- the HTML content remains recognizable

## Walkthrough

1. Start with the simple HTML page.
2. Type the `link rel="stylesheet"` line and create `styles.css`.
3. Type the `body` rule, save, and refresh.
4. Add the `h1`, `p`, and `a` rules one at a time.
5. Refresh after each visible change and connect the visual result to the CSS rule.

## Misconceptions To Watch

- Students may put style rules inside the HTML body.
- Students may expect CSS changes to work without linking the stylesheet.
- Students may think CSS changes the meaning of the content.

## Wednesday Bridge

The Wednesday demo applies the same CSS idea across multiple pages with reusable class names and shared design consistency.
