# Demo Notes - Monday Button Text Change

**Related Assignment:** Assignment 5 - DOM Interaction & Events  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Show the first full connection between HTML, JavaScript, an event, and a visible page update.

## Delivery Mode

Build the JavaScript live after the HTML is visible. Type the selector, function, and event listener in stages so students see exactly when the page becomes interactive.

## Concept Shown

- JavaScript selects existing HTML
- an event waits for a user action
- a function runs after the click
- `textContent` changes visible page content

## Walkthrough

1. Open the page before JavaScript is added or before the event listener exists.
2. Type the selector for `#message`.
3. Type the selector for `#updateButton`.
4. Type `updateMessage()`.
5. Add the click event listener and test the button.

## Misconceptions To Watch

- Students may think selecting an element changes it.
- Students may forget the `#` in an id selector.
- Students may expect the function to run before the click.

## Wednesday Bridge

The Wednesday demo adds input, validation, and clearer feedback so the interaction responds to user-provided data.
