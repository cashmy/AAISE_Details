# Demo Notes - Wednesday Input Feedback

**Related Assignment:** Assignment 5 - DOM Interaction & Events  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 12-18 minutes

## Purpose

Deepen Monday's button text-change demo by adding user input, validation, and clearer feedback.

## Delivery Mode

Build from the Monday button interaction. Type the input selector, value reading, and validation branch live. The finished files are the reference state.

## Walkthrough

1. Recall the Monday version where a button changed fixed text.
2. Add or inspect the input field.
3. Type the selector for `#nameInput`.
4. Read `.value`, trim it, and test with no input.
5. Add a name and click again.
6. Emphasize that the event does not run until the user clicks.

## Misconceptions To Watch

- Students may think `querySelector` changes the page by itself.
- Students may forget to read `.value` from an input.
- Students may expect an event handler to run immediately.

## Lab Bridge

Students should add a small interaction to their own page: click, input, visible output.

## Optional Extension

Add an input event listener so the message updates while typing, then compare that to click behavior.
