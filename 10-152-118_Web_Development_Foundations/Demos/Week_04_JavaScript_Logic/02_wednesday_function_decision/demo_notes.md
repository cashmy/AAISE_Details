# Demo Notes - Wednesday Function Decision

**Related Assignment:** Assignment 4 - Introduction to JavaScript  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Deepen Monday's values-and-conditions demo by moving decision logic into a reusable function.

## Delivery Mode

Start from the Monday decision idea. Type the function definition and function call live so students can see the difference between defining reusable logic and running it.

## Walkthrough

1. Recall the Monday version with variables and an `if / else`.
2. Type `getProgressMessage(currentScore, lateCount)`.
3. Add the conditional logic inside the function.
4. Call the function and store the returned message.
5. Change `score` and `lateSubmissions`, refresh, and predict the output.

## Misconceptions To Watch

- Students may expect all JavaScript to visibly change the page.
- Students may confuse function definition with function call.
- Students may not realize `return` sends a value back.

## Lab Bridge

Students should practice variables, conditions, and functions in small steps before adding visible page behavior.

## Optional Extension

Add one more test case by calling `getProgressMessage()` with different numbers directly in the console.
