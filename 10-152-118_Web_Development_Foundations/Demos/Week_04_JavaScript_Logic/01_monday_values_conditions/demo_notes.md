# Demo Notes - Monday Values And Conditions

**Related Assignment:** Assignment 4 - Introduction to JavaScript  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 8-12 minutes

## Purpose

Introduce JavaScript as step-by-step instructions with stored values and decisions.

## Delivery Mode

Type the JavaScript live. The finished files are the reference state, but the teaching value is in students watching values, conditions, and console output appear in small steps.

## Concept Shown

- variables store values
- `console.log()` makes output visible
- conditions choose between paths
- JavaScript can run without changing the page yet

## Walkthrough

1. Create `index.html` and link `script.js`.
2. Type the two variables and the first two `console.log()` statements.
3. Open the browser console and refresh.
4. Type the `if / else` block.
5. Change the score or on-time value and predict the output before refreshing.

## Misconceptions To Watch

- Students may expect all JavaScript to visibly change the page.
- Students may confuse text output with page content.
- Students may treat a condition as a question rather than a branch in execution.

## Wednesday Bridge

The Wednesday demo moves the same decision idea into a function so logic can be reused with different inputs.
