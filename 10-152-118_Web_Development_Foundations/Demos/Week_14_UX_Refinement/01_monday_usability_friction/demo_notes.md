# Demo Notes - Monday Usability Friction

**Related Assignment:** Assignment 14 - UX & Refinement  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-12 minutes

## Purpose

Show that a page can work and still be unclear or unpleasant to use.

## Delivery Mode

Use this as a before-state. Do not over-explain it at first. Let students name the friction they notice.

## Concept Shown

- working is not the same as usable
- labels, instructions, feedback, spacing, and button text affect experience
- UX refinement starts with noticing friction

## Walkthrough

1. Open the page and use it once.
2. Ask what is unclear.
3. Identify weak label text, vague button text, minimal feedback, and cramped spacing.
4. Make a short improvement list before showing the Wednesday refinement.

## Wednesday Bridge

The Wednesday demo revises the same interaction for clearer labels, spacing, feedback, and responsive behavior.
