# Demo Notes - Wednesday Refined Interaction

**Related Assignment:** Assignment 14 - UX & Refinement  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 12-18 minutes

## Purpose

Deepen Monday's friction demo by revising the same feature for clearer use.

## Delivery Mode

Start from the Monday before-state and apply refinements in small passes: copy, labels, spacing, feedback, then responsive behavior.

## Concept Shown

- UX refinement is intentional revision
- clearer labels reduce confusion
- feedback should tell users what happened
- responsive constraints support usability

## Walkthrough

1. Compare the heading and supporting copy.
2. Improve the input label and placeholder.
3. Improve the button text.
4. Improve the result message and validation feedback.
5. Resize the page and show the mobile-friendly panel behavior.

## Lab Bridge

Students should identify friction in their own project and make clear, explainable improvements.
