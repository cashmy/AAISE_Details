# Demo Notes - Monday Messy Working Code

**Related Assignment:** Assignment 7 - Structured JavaScript  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Show that working code can still be hard to read or maintain.

## Delivery Mode

Build or reveal the working version first. Type enough of the event handler live for students to see that the code works, then pause on the discomfort: everything is packed into one anonymous function.

## Concept Shown

- code can work and still need improvement
- repeated message-building can hide intent
- long event handlers become harder to read
- refactoring should preserve behavior

## Walkthrough

1. Run the demo and test several minute values.
2. Confirm that the behavior works.
3. Read the event handler aloud.
4. Ask what each part is responsible for.
5. Identify what could become named functions.

## Misconceptions To Watch

- Students may think refactoring means the code was wrong.
- Students may resist changing code once it works.
- Students may confuse shorter code with clearer code.

## Wednesday Bridge

The Wednesday demo refactors the same behavior into named functions with clearer responsibilities.
