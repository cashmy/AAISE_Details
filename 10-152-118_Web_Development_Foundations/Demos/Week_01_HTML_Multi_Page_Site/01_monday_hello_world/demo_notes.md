# Demo Notes - Monday Hello World

**Related Assignment:** Assignment 1 - HTML Multi-Page Site  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 5-8 minutes

## Purpose

Create the first visible win: one file, one page, something exists in the browser.

## Delivery Mode

Build this live by typing the full file. The finished `index.html` is a reference state, not the starting point for the demo.

## Concept Shown

Students see the minimum useful shape of an HTML page:

- document type
- `html`
- `head`
- `title`
- `body`
- heading
- paragraph

## Walkthrough

1. Create `index.html`.
2. Type the basic document structure and save.
3. Open or refresh the browser and point out the page title in the tab.
4. Type the `h1` and `p` elements, save, and refresh.
5. Change the heading or paragraph and refresh again.

## Misconceptions To Watch

- Students may expect the page to look polished immediately.
- Students may not realize the browser is reading the file.
- Students may confuse the tab title with the visible page heading.

## Wednesday Bridge

The Wednesday demo grows this first page into a small site with structure, navigation, and a second page.
