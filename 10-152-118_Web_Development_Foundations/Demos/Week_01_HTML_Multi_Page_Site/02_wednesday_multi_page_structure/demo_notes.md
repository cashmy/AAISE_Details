# Demo Notes - Wednesday Multi-Page Structure

**Related Assignment:** Assignment 1 - HTML Multi-Page Site  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Deepen the Monday Hello World page into a small site. Students should see that one simple page can grow into structured regions, navigation, lists, and multiple connected files.

## Delivery Mode

Begin from the Monday Hello World shape and build the added structure live. It is fine to paste repeated page scaffolding for `about.html`, but type the first navigation and section structure so students see how the site grows.

## Walkthrough

1. Start from or recreate the Monday `index.html`.
2. Add `header`, `nav`, `main`, `section`, and `footer` in visible stages.
3. Save and refresh after each meaningful addition.
4. Create `about.html`, using selective paste for repeated scaffolding if needed.
5. Add links between pages, click the About link, and return Home.
6. Open the source and connect visible page areas to HTML elements.

## Misconceptions To Watch

- Students may expect visual polish immediately.
- Students may confuse file names with page titles.
- Students may not realize links depend on exact file paths.

## Lab Bridge

Students will build their own small multi-page site. The transfer target is structure first: pages, headings, sections, and working navigation.

## Optional Extension

Add a third page live and deliberately mistype the link once to show how broken navigation happens.
