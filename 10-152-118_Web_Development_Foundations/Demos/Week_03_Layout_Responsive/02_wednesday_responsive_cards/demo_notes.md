# Demo Notes - Wednesday Responsive Resource Cards

**Related Assignment:** Assignment 3 - Layout & Responsive Design  
**Lecture Use:** Wednesday recorded lecture  
**Estimated Time:** 12-18 minutes

## Purpose

Deepen Monday's simple layout demo by revising a page so it responds to narrower screens. The key move is from "works at one size" to "adapts when conditions change."

## Delivery Mode

Start from the non-responsive layout problem. Type the responsive rule live and resize the browser before and after so the iteration is visible as a fix, not just a finished layout.

## Walkthrough

1. Start by recalling the Monday simple layout and its weakness when resized.
2. Open or rebuild the card layout at a desktop width.
3. Resize the browser before the media query is added and name the usability problem.
4. Type the `@media` rule and revised `grid-template-columns`.
5. Resize again until the media query changes the grid.
6. Emphasize that the HTML content did not change; the layout rule changed.

## Misconceptions To Watch

- Students may think responsive design means only shrinking text.
- Students may try to position every item manually.
- Students may not test different viewport widths.

## Lab Bridge

Students should revise their existing site so content is organized and usable on more than one screen size.

## Optional Extension

Change the breakpoint from `700px` to another value and discuss why breakpoints should respond to content, not just device names.
