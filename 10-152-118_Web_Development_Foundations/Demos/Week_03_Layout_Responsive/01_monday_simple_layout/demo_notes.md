# Demo Notes - Monday Simple Layout

**Related Assignment:** Assignment 3 - Layout & Responsive Design  
**Lecture Use:** Monday live lecture  
**Estimated Time:** 10-15 minutes

## Purpose

Show layout as intentional organization of space before adding responsive behavior.

## Delivery Mode

Build the layout in stages. Type the structural HTML regions first, then add the layout CSS live so the page visibly moves from normal document flow into a two-column arrangement.

## Concept Shown

- content areas can be grouped into regions
- Flexbox can place regions next to each other
- spacing and width affect readability
- layout can work at one screen size and still need refinement

## Walkthrough

1. Type or reveal the header, main content, and sidebar regions.
2. Save and view the page before layout CSS.
3. Add `.page { display: flex; }` and the gap/width rules.
4. Refresh and identify how the page changed.
5. Resize the browser and let students notice the weakness: the layout does not adapt yet.

## Misconceptions To Watch

- Students may think layout is only decoration.
- Students may treat Flexbox as magic rather than a rule applied to a container.
- Students may assume working on a desktop means the page is finished.

## Wednesday Bridge

The Wednesday demo revises the layout into responsive cards that adapt when the screen gets narrower.
