# Course Competency Framework

## Course Information

**Course Title:** HTML, CSS & JavaScript  
**Course Number:** 10-152-118  
**Credits:** 3  
**Lecture Hours:** 36  
**Lab Hours:** 36  
**Total Hours:** 72  
**Instructional Level:** 10  

---

## Description

Learners develop foundational web development skills using HTML, CSS, and JavaScript to create structured, styled, and interactive web pages. The course emphasizes building multi-page websites, applying design principles for usability and readability, and implementing basic interactivity through JavaScript. Learners practice debugging and refining web applications using progressive techniques and are introduced to AI-assisted tools to support development. By the end of the course, students are able to design, build, and explain functional web solutions.

---

## Framework Design Note

This version expands the WIDS Course Competency Framework into a detailed source artifact that supports a direct technical/core competency structure. The first six competencies represent course-specific technical performance. The final six competencies represent observable core abilities refracted through web development work.

The current 118 Master Rubric System contains five technical categories and six core ability categories. This framework preserves those five technical categories and adds a sixth technical competency for responsible AI-assisted web development and accountability. That addition reflects the course AI Use Addendum and creates the same 12-competency structure used in the Python Programming framework.

## 1. Structure web content using semantic HTML

**MRS Mapping:** T1. Structure (HTML)  
**Domain:** Cognitive  
**Level:** Applying  
**Status:** WIP  

### Assessment Strategies

* Multi-page website assignments
* HTML structure checkpoints
* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Create structured web pages using semantic HTML elements
* Organize content logically using headings, paragraphs, lists, links, and media
* Apply consistent page organization
* Build multi-page website structures
* Ensure page structure supports styling, navigation, accessibility, and interactivity

### Learning Objectives

* Define HTML structure and purpose
* Identify common semantic HTML elements
* Explain how page structure supports styling and interaction
* Describe how multi-page sites organize information

**Domain:** Cognitive  
**Level:** Creating  
**Status:** WIP

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

## 6. Use AI-assisted web development responsibly and transparently

**MRS Mapping:** T6. AI-Assisted Web Development and Accountability  
**Domain:** Cognitive  
**Level:** Evaluating  
**Status:** WIP  

### Assessment Strategies

* AI-assisted debugging or refinement activities
* Project documentation
* AI-use justification activities
* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Use AI tools within assignment boundaries and course phase expectations
* Avoid using AI to bypass required foundational practice
* Evaluate AI-generated or AI-suggested HTML, CSS, and JavaScript before using it

* Describe appropriate AI use in staged web development learning

* Explain how responsible AI use requires validation, revision, and accountability
* Describe how AI can support troubleshooting, refinement, and extension without replacing understanding

# Course Alignment Notes

This course provides foundational web development skills that complement programming and algorithm coursework. Students develop the ability to create structured, styled, interactive, and explainable web applications while practicing progressive debugging, responsible tool use, and iterative improvement. The 12-competency structure aligns the detailed WIDS source artifact with the broader MRS-based curriculum model used across the course sequence.
