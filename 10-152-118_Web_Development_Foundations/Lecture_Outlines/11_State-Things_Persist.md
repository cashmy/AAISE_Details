# 🧭 **WEEK 11 — MONDAY LECTURE OUTLINE**

**Title:** *Week 11 — Integration: Bringing It All Together*

---

## **1. Opening Frame**

> “Up to this point, you’ve learned separate skills.
> This week, we focus on combining them into one system.”

* Shift from isolated features → integrated behavior

---

## **2. Course Positioning**

> “You now have all the major pieces:

* structure
* style
* layout
* logic
* data
* input

Now we connect them.”

---

## **3. Core Concepts**

* Integration vs isolated features
* Flow of an application:

  * input → processing → output
* Connecting components:

  * DOM + events + data
* Managing interactions across parts
* Maintaining clarity while combining features

---

## **4. Demonstration / Example Layer**

* Show:

  * simple integrated flow:

    * input → processed → displayed

* Show:

  * multiple features working together

👉 Emphasize:

* how pieces connect
* not just what they do

---

## **5. Common Mistakes / Watch-Fors**

* features working separately but not together
* overly complex logic
* unclear data flow
* breaking existing functionality

---

## **6. Tuesday Lab Bridge**

> “In lab, your goal is to connect at least two parts of your system.”

Focus:

* integrate features
* ensure flow works
* keep it simple

---

## **7. Closing Frame**

> “A system is not just parts—it’s how those parts work together.”

---

---

# 🧭 **WEEK 11 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 11 — System Thinking & Flow*

---

## **1. Re-Anchor the Week**

> “This week is about thinking in terms of systems, not features.”

---

## **2. Deep Concept Focus**

* Systems have flow:

  * input → logic → output
* Components depend on each other
* Clarity matters more as systems grow
* Integration introduces complexity

---

## **3. Common Confusion Patterns**

* “Each part works, but together it breaks”
* “I don’t know where the problem is”
* “The flow is unclear”

---

## **4. Thinking Tools / Heuristics**

* “What is the flow from input to output?”
* “Where does this data go next?”
* “What depends on this?”
* “Can I trace the system step-by-step?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, improve how your system flows.”

Examples:

* simplify connections
* clarify logic
* fix broken interactions

---

## **6. Closing Reinforcement**

> “Understanding flow is what turns code into systems.”

---
