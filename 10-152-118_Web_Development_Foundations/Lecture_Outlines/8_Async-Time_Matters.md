# 🧭 **WEEK 8 — MONDAY LECTURE OUTLINE**

**Title:** *Week 8 — Data Structures: Organizing Information*

---

## **1. Opening Frame**

> “So far, you’ve worked with individual values.
> This week, you’ll start organizing and working with collections of data.”

* Shift from single variables → grouped data

---

## **2. Course Positioning**

> “You now understand logic and structure.
> Now we focus on how data is stored and used.”

* connects to:

  * variables (Week 4)
  * structure (Week 7)

---

## **3. Core Concepts**

* Arrays (lists of values)
* Objects (key-value pairs)
* Accessing data (index, property)
* Iteration (looping through data — concept level)
* Data as input to behavior

---

## **4. Demonstration / Example Layer**

* Show:

  * array of items → display
* Show:

  * object → access properties
* Show:

  * simple loop → process items

👉 Emphasize:

* data drives behavior

---

## **5. Common Mistakes / Watch-Fors**

* confusing arrays vs objects
* incorrect indexing
* trying to memorize syntax
* losing track of structure

---

## **6. Tuesday Lab Bridge**

> “In lab, your goal is to use data—not just create it.”

Focus:

* create simple data structures
* use them to drive behavior
* connect data to UI

---

## **7. Closing Frame**

> “Data gives your application something to work with.”

# 🧭 **WEEK 8 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 8 — Thinking in Data*

---

## **1. Re-Anchor the Week**

> “This week is about organizing information so your code can use it.”

---

## **2. Deep Concept Focus**

* Data structures represent real-world information
* Arrays = collections
* Objects = structured items
* Code becomes more powerful with organized data

---

## **3. Common Confusion Patterns**

* “When do I use an array vs object?”
* “Why is this undefined?” → incorrect access
* “I can’t keep track of the structure”

---

## **4. Thinking Tools / Heuristics**

* “Is this a list or a single item?”
* “What properties does this thing have?”
* “How do I access what I need?”
* “Can I describe the structure clearly?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, focus on making your data easier to work with.”

Examples:

* clean up structure
* simplify access
* connect data to UI more clearly

---

## **6. Closing Reinforcement**

> “Well-structured data makes everything else easier.”

---

# 🧠 Instructor Notes (For You)

This is a **moderate cognitive jump**.

---

## Students may:

* get confused by structure
* mix concepts (array vs object)
* feel less confident

---

## Your role:

* keep examples simple
* avoid deep nesting
* reinforce patterns

---

## Critical reinforcement:

> “You don’t need complex data—just clear data.”
