# 🧭 **WEEK 4 — MONDAY LECTURE OUTLINE**

**Title:** *Week 4 — JavaScript: This Is Programming*

---

## **1. Opening Frame**

> “Up to this point, you’ve been describing what a page is.
> This week, you start controlling what it does.”

* Acknowledge shift
* Normalize discomfort

---

## **2. Course Positioning**

> “You now have structure, style, and layout.
> Now we add behavior.”

* HTML → structure
* CSS → appearance
* JS → behavior

👉 Reinforce separation again

---

## **3. Core Concepts**

* What a program is (step-by-step execution)
* Variables (storing values)
* Conditions (`if / else`)
* Functions (reusable logic)
* Output (`console.log`)

---

## **4. Demonstration / Example Layer**

* Show:

  * simple variable + output
* Show:

  * condition changing output
* Show:

  * basic function

👉 Keep everything:

* small
* readable
* linear

---

## **5. Common Mistakes / Watch-Fors**

* Trying to memorize instead of understand
* Losing track of variable values
* Confusing syntax with logic
* Expecting immediate mastery

---

## **6. Tuesday Lab Bridge**

> “In lab, your goal is not to build something complex.
> Your goal is to understand how code executes step-by-step.”

Focus:

* simple programs
* readable logic
* basic flow

---

## **7. Closing Frame**

> “If you can explain what your code is doing—you are on track.”

# 🧭 **WEEK 4 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 4 — Thinking Like a Program*

---

## **1. Re-Anchor the Week**

> “This week is about understanding how a program thinks.”

---

## **2. Deep Concept Focus**

* Programs execute line-by-line
* Variables change over time
* Conditions control flow
* Functions organize behavior

👉 Emphasize process, not syntax

---

## **3. Common Confusion Patterns**

* “Why didn’t this run?” → order of execution
* “Why is this value wrong?” → variable misunderstanding
* “This looks right but doesn’t work” → logic error

---

## **4. Thinking Tools / Heuristics**

* “What is the value right now?”
* “What line runs next?”
* “What condition is true?”
* “What does this function actually do?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, focus on making your code clearer—not more complex.”

Examples:

* rename variables
* simplify logic
* add clarity

---

## **6. Closing Reinforcement**

> “Programs are not magic—they follow instructions.”

---
