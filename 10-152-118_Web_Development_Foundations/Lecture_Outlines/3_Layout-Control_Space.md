# 🧭 **WEEK 3 — MONDAY LECTURE OUTLINE**

**Title:** *Week 3 — Layout: Controlling Space*

---

## **1. Opening Frame**

> “So far, you’ve been styling individual elements.
> This week, you’ll start controlling how those elements are arranged.”

* Shift from *elements* → *relationships between elements*

---

## **2. Course Positioning**

> “You now have structure and style.
> Now we control how everything fits together.”

* HTML → what it is
* CSS → how it looks
* **Layout → how it is arranged**

👉 This is a new dimension

---

## **3. Core Concepts**

* Default layout (stacking behavior)
* Introduction to Flexbox:

  * container vs items
  * direction (row/column)
* Alignment and spacing (basic level)
* Layout vs styling (critical distinction)

---

## **4. Demonstration / Example Layer**

* Show:

  * default stacked layout
  * same content using Flexbox

* Show:

  * horizontal vs vertical alignment
  * spacing changes

👉 Emphasize:

* layout changes structure of space—not appearance

---

## **5. Common Mistakes / Watch-Fors**

* Using margins instead of layout tools
* Confusing alignment vs spacing
* Applying Flexbox to wrong element (child vs container)
* Trying to control everything at once

---

## **6. Tuesday Lab Bridge**

> “In lab, your goal is to control one section of your layout—not the entire page.”

Focus:

* apply Flexbox to one area
* make layout intentional
* don’t try to perfect everything

---

## **7. Closing Frame**

> “Layout is about relationships—not individual elements.”

---

# 🧭 **WEEK 3 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 3 — Layout Thinking & Responsiveness*

---

## **1. Re-Anchor the Week**

> “This week is about controlling space—not just moving things around.”

---

## **2. Deep Concept Focus**

* Layout is a system, not a set of tricks
* Containers control behavior
* Elements respond within that system
* Introduction to responsive thinking:

  * screen size matters
  * layout is not fixed

---

## **3. Common Confusion Patterns**

* “Why won’t this align?” → wrong container
* “Why is spacing weird?” → mixing margin with layout
* “It works on my screen but not smaller” → no responsive thinking

---

## **4. Thinking Tools / Heuristics**

* “What is the container?”
* “What direction is this layout?”
* “What happens if the screen shrinks?”
* “Am I controlling layout or just pushing things around?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, improve one layout and add one responsive adjustment.”

Examples:

* adjust layout for smaller screen
* improve spacing/alignment

---

## **6. Closing Reinforcement**

> “Good layout makes content easier to understand.”

---
