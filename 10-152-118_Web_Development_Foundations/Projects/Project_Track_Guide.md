# **Project Track Guide — Course Project Selection**

---

## **Overview**

Throughout this course, you will build and improve a single project over time.

Each week, you will:

* add new features
* refine your existing work
* connect new concepts to what you have already built

You may:

* choose one of the suggested project tracks below
* OR propose your own idea (subject to approval)

---

## **Why This Approach**

Instead of starting over each week, you will:

* build on your existing system
* see how different concepts connect
* improve your work through iteration

This reflects how real software is developed.

---

# **Project Track Options**

---

## 🔹 Option 1 — Personal Dashboard

Create a personal dashboard that displays information about you or a chosen topic.

### Examples of Features:

* profile or introduction section
* list of links or resources
* dynamic content updates
* interactive elements (buttons, toggles)
* data display (later in the course)

### Why Choose This:

* flexible and creative
* easy to expand over time
* works well for all assignments

---

## 🔹 Option 2 — Task / To-Do Application

Create an application that allows users to manage tasks.

### Examples of Features:

* add and remove tasks
* mark tasks as complete
* filter or organize tasks
* manage state over time
* use forms for input

### Why Choose This:

* strong focus on JavaScript and logic
* naturally supports interaction and state
* closely resembles real-world applications

---

## 🔹 Option 3 — Product or Service Website

Create a multi-page website for a product, service, or idea.

### Examples of Features:

* multiple pages (Home, About, Services)
* navigation system
* product or service listings
* user interaction (forms, buttons)
* improved layout and user experience

### Why Choose This:

* strong focus on HTML/CSS and layout
* good for design and usability practice
* scalable with interactivity

---

## 🔹 Option 4 — Content Explorer / Resource Hub (Three Variants)

Build an application that organizes and presents information around a topic.

You may choose one of the following directions:

---

### 🔸 Option 4A — Content Explorer

Organize and display content around a topic of interest.

#### Examples:

* articles or summaries
* categorized content
* topic-based sections

#### Later Extensions:

* filtering content
* dynamic updates
* JSON-based content

---

### 🔸 Option 4B — Event / Activity Planner

Create a system to organize events, activities, or schedules.

#### Examples:

* event listings
* schedules or timelines
* categorized activities

#### Later Extensions:

* form input for new events
* filtering or sorting
* state-based updates

---

### 🔸 Option 4C — Resource Hub

Create a collection of useful resources around a topic.

#### Examples:

* categorized links
* descriptions or summaries
* navigation by topic

#### Later Extensions:

* search/filter functionality
* saved selections
* JSON-driven resource lists

---

### Why Choose Option 4:

* starts simple and structured
* scales naturally over time
* connects well to later topics like data and state
* supports both design and logic development

---

## 🔹 Option 5 — Your Own Idea (Approval Required)

You may propose your own project.

### Requirements:

Your idea must:

* be appropriate for your current skill level
* include interactivity (JavaScript)
* be achievable within the course timeline

Your idea will be reviewed and may be adjusted before approval.

---

# **Starter Templates (Optional)**

Starter templates may be provided to help you begin.

You may:

* use a template as a starting point
* modify it as needed
* or build your project from scratch

---

# **Important Guidelines**

* Start simple—your project will grow over time
* You are not expected to build everything at once
* Each week introduces new capabilities
* Improvement and iteration are expected

---

# **Choosing Your Project**

Before beginning Week 1:

* Select one project track
* OR submit a proposed idea for approval

---

# **Final Note**

> The goal is not to build the most complex project.
> The goal is to build something you understand—and improve it over time.
