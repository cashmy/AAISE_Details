# **PageForge — Phase Constraint Template**

---

## **Purpose**

This template defines the fine-grained instructional constraints for generating `PageForge` milestones.

It exists because the roadmap is intentionally high-level, while milestone generation needs more precise control over:

* what may appear in a given week
* what may appear in a given phase of that week
* what must not appear yet
* how mature or incomplete the artifact should feel

This template should be copied into the live `PageForge_Phase_Constraints.md` document and filled in as lecture development becomes more concrete.

---

## **How to Use This Template**

For each week:

* create one `Build Phase` section
* create one `Refine Phase` section
* define what the LLM must include, may include, and must not include yet
* include stage-authenticity guidance so the artifact feels correct for the point in the course

These constraints should be treated as a governing artifact during milestone generation.

If the roadmap and the phase constraints differ in precision, the phase constraints should control the generation.
