# Creative Project Purpose And Constraints Template

**Course:** 10-152-118 Web Development Foundations  
**Purpose:** Help students turn a creative topic into a focused web project that has a user, a purpose, and realistic course constraints.

---

## Why This Template Exists

A project topic is not the same thing as a project purpose.

This is a topic:

```text
I want to make a website about Kamen Rider.
```

That may be a good starting point, but it is not yet a project plan.

A project plan explains:

- who the project is for
- what the user can do
- what goal or problem the project supports
- what will be built first
- what will wait until later
- how the project will meet the course requirements

Creative freedom is allowed.

Creative freedom still needs structure.

---

## The Core Question

Before building, answer this:

```text
What does this project help a user do?
```

Examples:

```text
This project helps new fans learn the basic eras, characters, and themes of Kamen Rider.
```

```text
This project helps fans browse recommended Kamen Rider starting points based on what kind of story they like.
```

```text
This project helps users organize favorite Kamen Rider seasons, characters, and links in one place.
```

## Student Planning Template

Copy and complete this before starting or revising a creative project direction.

### 1. Creative Topic

```text
My creative topic is:
```

### 2. Intended User

```text
The main user/audience is:
```

Choose one primary audience.

Examples:

- a person who has never heard of the topic
- a beginner fan
- an existing fan
- a collector
- a student looking for resources
- a viewer deciding where to start

### 3. Project Purpose

```text
This project helps users:

So they can:
```

Example:

```text
This project helps users compare beginner-friendly Kamen Rider seasons
so they can decide which one they might want to watch first.
```

### 4. Main User Actions

What will the user be able to do on the site?

```text
The user will be able to:

1.
2.
3.
```

Keep these actions small and realistic.

Examples:

- read an introduction
- move between pages
- browse categories
- click a button to show more information
- filter or sort a small list
- save a favorite item
- complete a simple form

### 5. Minimum Project Version

What is the simplest useful version of this project?

```text
The minimum version needs:

1.
2.
3.
```

This is the version that must work before extra features are added.

### 6. Creative Freedom Areas

Where do you want creative control?

```text
I want creative freedom with:

1.
2.
3.
```

Examples:

- topic
- visuals
- colors
- page names
- written content
- images
- categories
- character or media examples
- tone or style

### 7. Course Requirement Areas

These parts must still follow the assignment requirements.

```text
I understand that I still need to show:

1. HTML structure
2. CSS styling and layout
3. JavaScript interaction
4. debugging and revision
5. data or state when assigned
6. forms and input when assigned
7. usability and refinement
```

### 8. Out Of Scope For Now

What will not be built yet?

```text
I will not build yet:

1.
2.
3.
```

Examples:

- full fan wiki
- hundreds of pages
- user accounts
- real login
- real comments
- real database
- video streaming
- copyrighted media archive
- advanced animations

Out of scope does not mean "never."

It means "not required for the current course project."

## Approval Check

The project direction is ready for approval when these statements are clear:

```text
My project topic is:

My project helps this user:

The main purpose is:

The first version will include:

The project will meet weekly assignments by:
```

---

## Example: Kamen Rider Topic

### Not Yet Focused

```text
I want to make a website about the coolness of Kamen Rider.
```

This is enthusiastic, but too broad.

### More Focused

```text
I want to make a beginner-friendly Kamen Rider guide that helps new viewers
learn what the series is, compare a few starting points, and save a favorite
season to remember later.
```

This is stronger because it has:

- a user: new viewers
- a purpose: help them understand and choose a starting point
- possible pages: home, eras, recommended starts
- possible interaction: show details, filter categories, save favorite
- realistic scope: a few examples, not a full wiki

---

## Instructor Response Pattern

Use this pattern when responding to a creative project request.

```text
Yes, this topic can work as long as we turn it into a focused web project.

Right now, "a website about [topic]" is a topic, not yet a project purpose.

Before I approve the direction, tell me:

1. Who is the site for?
2. What does the site help that user do?
3. What are three things the first version will include?
4. What will you intentionally leave out for now?

Once those are clear, we can connect your creative idea to the weekly HTML,
CSS, and JavaScript requirements.
```
