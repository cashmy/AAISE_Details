# Creative Project Basic Submission Template

**Course:** 10-152-118 Web Development Foundations  
**Purpose:** Help students use a creative project idea while still meeting the weekly assignment requirements.

---

## When To Use This

Use this template if you are choosing your own creative project direction instead of following one of the standard examples closely.

Creative freedom is allowed.

Creative freedom does not remove the assignment requirements.

Each weekly submission still needs to show the required course concept for that week.

---

## Basic Rule

Your project can be about almost any approved topic, but each assignment must still answer this question:

```text
Where can I see this week's required skill in your project?
```

If the required skill is not visible, the project may be creative, but it may not meet the assignment.

---

## Student Submission Template

Copy and complete this section when submitting a creative project assignment.

### 1. Project Identity

```text
Project name:

Project topic or theme:

Selected project track:

One-sentence description:
```

### 2. This Week's Assignment Requirement

```text
Assignment number/week:

Main required skill for this assignment:

Where this skill appears in my project:
```

Examples of required skills might include:

- HTML structure
- navigation between pages
- CSS styling
- responsive layout
- JavaScript interaction
- DOM updates
- debugging evidence
- functions
- async behavior
- data/API use
- state
- forms
- usability refinement

### 3. What I Built Or Changed

```text
This week I added or changed:

1.
2.
3.
```

Keep this simple. Name the actual changes someone can see in your files or browser.

### 4. Required Evidence

```text
Files I changed:

Page/view/section where the requirement can be tested:

Steps to test it:
1.
2.
3.
```

Example:

```text
Page/view/section where the requirement can be tested:
The Resources page.

Steps to test it:
1. Open resources.html.
2. Click the "Show beginner resources" button.
3. Confirm the resource list changes on the page.
```

### 5. Creative Choices

```text
The creative choices I made were:

1.
2.
3.
```

Creative choices may include topic, colors, layout direction, wording, images, page names, features, or user experience decisions.

### 6. What Is Not Finished Yet

```text
The project is not finished in these ways:

1.
2.
3.
```

This is not a penalty. Real projects are built in stages.

### 7. AI Use, If Any

```text
Did I use AI for this assignment? Yes / No

If yes, what did I ask AI to help with?

What did I manually write, review, change, or verify myself?
```

AI may help you understand, debug, or improve your work when allowed by the course policy.

You are still responsible for understanding and explaining your submitted code.

---

## Instructor Review Notes

For a creative project submission, evaluate the weekly requirement first.

Useful review questions:

- Does the submission clearly identify the current assignment requirement?
- Can the required skill be found in the submitted files?
- Can the student explain where the requirement appears?
- Does the creative direction still fit the course level and timeline?
- Is the student adding complexity faster than they can explain it?

Recommended instructor response pattern:

```text
Approved direction:

Required adjustment before next submission:

Keep:

Do not add yet:
```

---

## Simple Reminder

```text
Your idea can be creative.
Your evidence must be specific.
Your project should grow one assignment at a time.
```
