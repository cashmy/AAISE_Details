# Week 1 Image Generation Prompts

**10-152-118 Web Development Foundations**

---

# Purpose

This companion artifact expands the compact image notes from the Week 1 deck
sources into explicit image-generation prompts for browser-based ChatGPT image
generation.

Primary workflow:

- Copy one prompt block at a time into the browser-based ChatGPT image tool.
- Use Codex image generation only as a fallback if the browser image result is
  significantly unusable.
- Reject any image that makes Week 1 look like a polished CSS showcase. Week 1
  is about HTML structure, file paths, browser rendering, and early confidence.

Source decks:

- `W01A_HTML_Foundations_Live.md`
- `W01B_HTML_Structure_Iteration_Recorded.md`

Global style guidance:

- clean instructional PowerPoint visual
- white or very light background
- modern, flat, classroom-friendly style
- large readable labels
- minimal decorative detail
- restrained SWTC-friendly colors: navy, teal, warm gold, white, soft gray
- no complex screenshots unless requested
- no dense code blocks
- no polished landing-page mockups
- no futuristic, hacker, or AI-themed imagery

# Week 1 Monday Live Prompts

## W01A Slide 1 - Something Exists

```text
Create a clean instructional PowerPoint visual showing a first HTML file becoming a simple browser page.

Use a white or very light background. Show a simple split layout:

Left side: a plain document file labeled "index.html"
Right side: a plain browser window showing one heading and one short paragraph

Add a small note:
"First goal: make something exist in the browser."

The visual should feel calm, beginner-friendly, and intentionally unpolished. It should communicate that Week 1 success is about structure and visibility, not visual design.

Avoid complex website mockups, CSS styling, JavaScript, stock-photo people, dramatic celebration imagery, dense code, or a polished landing page.
```

## W01A Slide 2 - Web Page Layers

```text
Create a clean instructional PowerPoint visual showing the three main web development layers.

Use a white or very light background. Show three stacked horizontal layers:

Top layer: HTML - structure
Middle layer: CSS - appearance
Bottom layer: JavaScript - behavior

Highlight the HTML layer. Keep CSS and JavaScript visible but quieter to show that they are coming later.

Add a small note:
"Today we start with structure."

Use large readable labels and simple icons only if they remain subtle.

Avoid framework logos, React or Node references, 3D technology stacks, dark developer imagery, or tiny unreadable text.
```

## W01A Slide 4 - File To Browser Loop

```text
Create a clean instructional PowerPoint visual showing the first HTML development loop.

Use a white or very light background. Show four connected steps from left to right:

1. Create file
2. Save
3. Open in browser
4. Refresh

Use simple icons for a document file, save action, browser window, and circular refresh arrow. Use soft gray connectors and a teal highlight on the browser result.

Add a small note:
"Change the file. Save it. Refresh the browser."

Keep the visual uncluttered and readable from a projector.

Avoid complicated IDE panels, deployment/cloud imagery, server racks, terminal windows, or anything implying students need a web server in Week 1.
```


## W01A Slide 6 - Parked For Later

## W01A Slide 7 - HTML Document Shape

```text
Create a clean instructional PowerPoint visual showing the basic shape of an HTML document.

Use a white or very light background. Show a nested-box diagram:

Outer box: html
Upper inner box: head - information about the page
Lower inner box: body - visible page content

Inside the head box, include a small label: title
Inside the body box, include small labels: h1 and p

Use large readable labels and a calm classroom-friendly style. The purpose is to show document structure, not to teach a full code listing.

Avoid dense code, syntax overload, dark hacker aesthetics, browser developer tools, or decorative website design.
```

## W01A Slide 11 - Title Versus Heading

```text
Create a clean instructional PowerPoint visual explaining that the browser tab title and the visible page heading are different HTML elements.

Use a white or very light background. Show a simplified browser window:

Callout 1 points to the browser tab and says "title element"
Callout 2 points to a large visible page heading and says "h1 element"

The page itself should be plain and unstyled, with no extra layout beyond the heading and one short line of body text.

Add a small note:
"One names the tab. One appears on the page."

Avoid realistic brand browser chrome, complex navigation, polished website styling, screenshots with tiny text, or extra callouts.
```

## W01A Slide 12 - Working Beats Pretty

```text
Create a clean instructional PowerPoint visual comparing a plain working page to a decorated broken page.

Use a white or very light background. Show two side-by-side cards:

Left card: a plain unstyled page with a working check mark
Right card: a visually decorated page with a broken link warning symbol

Add a clear note:
"In Week 1, working beats pretty."

Use calm colors and a non-shaming tone. The message should encourage students to prioritize correct files, links, and structure before visual design.

Avoid ugly chaotic design, harsh red failure screens, shaming student work, complicated error messages, or a polished professional website.
```

## W01B Slide 11 - Three Page Assignment Target

```text
Create a clean instructional PowerPoint visual showing a simple three-page HTML site.

Use a white or very light background. Show three document cards labeled:

Home
About
Topic

Connect the cards with two-way arrows to represent navigation links between pages. Each card should include tiny visual hints of a heading and paragraph, but no readable dense text.

Add a small note:
"Each page should link to the others."

Use navy outlines, teal arrows, and plenty of whitespace.

Avoid complex sitemap diagrams, dropdown menus, many-page corporate sites, website thumbnails with CSS design, or confusing folder structures.
```

# Week 1 Wednesday Recorded Prompts

```text
Create a clean instructional PowerPoint visual showing the progression from one HTML page to a small multi-page site.
```


## W01B Slide 9 - Href And File Name Match

```text
Create a clean instructional PowerPoint visual showing how a broken link can come from an exact-match problem.

Use a white or very light background. Show a file card named:
about.html

Next to it, show an href value:
abot.html

Use a magnifying glass or callout to highlight the missing letter. Add a small warning marker between them, but keep the tone calm and instructional.

Add a small note:
"File names and href values must match exactly."

Avoid scary error screens, 404 memes, complex folder trees, red alarm imagery, or dense code blocks.
```
