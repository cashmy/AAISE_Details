# **Executive Summary (ES-01)**

**HTML, CSS & JavaScript — Integrated Systems Instruction Model**

---

## **Overview**

This course maintains standard academic competencies while refining instructional delivery to better reflect how modern web systems are built and understood.

Students learn HTML, CSS, and JavaScript as distinct technologies, but experience them as **interacting layers within a system**. This approach improves comprehension, debugging ability, and readiness for real-world development.

---

## **Instructional Model**

Traditional delivery often presents topics in isolation:

> HTML → CSS → JavaScript

This course preserves those distinctions but organizes learning around system behavior:

> **Structure → Style → Behavior → Systems → Integration**

Students first gain clarity in each layer, then progressively combine them through guided and applied work.

---

## **Visual Progression**

```
FOUNDATIONS → BEHAVIOR → SYSTEMS → INTEGRITY → CAPSTONE

Structure     Programming    Data & State     Optimization     Independent Build
HTML          JavaScript     Async / APIs     Performance      Integration
              DOM            Modules          Security         Presentation

Layer Awareness → Layer Interaction → System Thinking → System Refinement → System Ownership
```

---

## **Assessment Approach**

Assessment remains fully aligned with institutional standards:

* All **WIDS competencies are preserved** 
* Evaluation is **criterion-based and measurable**
* A standardized rubric (MRS-02) is used across all assignments

Each assignment evaluates multiple competencies simultaneously, ensuring:

* consistent measurement
* increasing complexity
* full coverage of required outcomes

Institutional **Core Abilities** are embedded through observable behaviors such as collaboration, communication, and professionalism .

---

## **Use of Tools and AI**

Students progress through a controlled tooling model:

* **Manual (Native):** foundational understanding
* **Assisted (AI):** explanation and debugging
* **Library (Frameworks):** acceleration after understanding

This ensures that tools enhance learning rather than replace it.

---

## **Workforce Alignment**

The course reflects modern development practices:

* Pair programming (collaborative problem solving)
* Iterative debugging and refinement
* Multi-layer system interaction
* Remote communication and presentation

Students are evaluated on both **technical outcomes** and **professional behaviors**, aligning directly with employer expectations.

---

## **Benefits**

This model:

* Improves student understanding of how systems actually work
* Strengthens debugging and problem-solving skills
* Maintains clear, measurable assessment standards
* Reduces cognitive overload through staged integration
* Aligns academic outcomes with workforce expectations

---

## **Summary**

> This course maintains traditional academic structure while aligning instruction more closely with how modern web systems are built, understood, and maintained.
