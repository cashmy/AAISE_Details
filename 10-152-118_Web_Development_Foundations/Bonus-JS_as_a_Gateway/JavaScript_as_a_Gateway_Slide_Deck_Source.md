# JavaScript as a Gateway - Slide Deck Source

**Course:** Web Development Foundations  
**Lecture type:** Bonus or early JavaScript SKY-Bounce lecture  
**Student-facing title:** JavaScript as a Gateway  
**Instructor-facing structure:** SKY to CORE to BASE, with a closing summary  
**Design pattern:** Concept slide first, full-image slide second  

## Instructor Use

This deck is designed for live delivery. Each concept appears first as a text-based slide so students can focus on the presenter explanation. The following slide uses the full visual image as a synthesis and guided review anchor.

Keep SKY, CORE, BASE, and SKY-Bounce as instructor-facing terms unless you choose to name them explicitly in class.

---

### SLIDE 1 - OPENING FRAME

Mode: SKY

Student-visible text:

```text
JavaScript as a Gateway

From Web Foundations to Modern Frontend Development

You have learned the layers.
Now we can look at the map.
```

Presenter notes:

- Set the tone as orientation, not a new list of required tools.
- Tell students this lecture explains why the JavaScript unit matters beyond the immediate syntax and DOM work.
- Emphasize that the goal is recognition and direction. They do not need to master every name in the ecosystem.

Visual:

- Layout: Title-centered opening slide with minimal text.
- Content: Course title, subtitle, and a calm web-development visual accent if desired.
- Purpose: Establish the SKY-Bounce frame before moving into the ecosystem map.

### SLIDE 11 - CONTRAST

Mode: CORE

Student-visible text:

```text
Languages and Frameworks

JavaScript:
- a programming language

TypeScript:
- a typed layer built on JavaScript

React, Vue, Angular, Svelte:
- tools for building interfaces

Next.js, Nuxt, SvelteKit:
- tools for organizing applications
```

Presenter notes:

- Keep the distinction simple: languages express logic, frameworks organize recurring work.

### SLIDE 14 - SYSTEM

Mode: CORE

Student-visible text:

```text
Metaframeworks Organize Applications

- React helps organize UI.
- Next.js helps organize a React application.
- Vue helps organize UI.
- Nuxt helps organize a Vue application.
- Svelte helps organize UI.
- SvelteKit helps organize a Svelte application.

```

Presenter notes:

```text
Component Library Quick Reference
```
