# Week 17 Guide - AI Use Explanation

## Purpose

This guide helps you explain any AI assistance used during your capstone project.

AI may assist your work, but it may not replace your responsibility for understanding, testing, revising, and explaining the final result.

This guide follows the course's standard AI use policy and the Web Development Foundations AI use addendum.

## The Main Standard

The main question is not only:

> Did AI help produce this work?

The more important question is:

> Can you understand, justify, test, revise, and explain the final result?

If you used AI, you are still responsible for the final HTML, CSS, JavaScript, design decisions, behavior, and project explanation.

## Acceptable AI Support For The Capstone

When allowed by the instructor, AI may help with:

* brainstorming ways to organize a feature
* explaining unfamiliar HTML, CSS, JavaScript, or browser behavior
* suggesting improvements to code organization
* helping diagnose a bug after you have attempted to understand it
* comparing possible approaches
* polishing explanation or presentation wording
* suggesting refinements or stretch features

AI support should help you think and revise. It should not replace your authorship.

## Unacceptable AI Use

For this capstone, AI may not be used to:

* submit code you cannot explain
* copy generated HTML, CSS, or JavaScript without checking and revising it
* bypass required project work
* hide meaningful AI use when disclosure is required
* present AI-generated output as if no human decisions were involved
* avoid learning the structure and behavior of your own project

If you cannot explain a part of your project clearly, you do not yet own that part of the solution.

## What To Be Ready To Explain

If you used AI, be ready to explain:

* what part of the project AI helped with
* what you asked AI to do
* what AI suggested or produced
* what you accepted, changed, or rejected
* how you tested or verified the result
* what design, layout, content, data, or logic decisions remained yours

You may be asked follow-up questions during the presentation.

## Web Development Explanation Areas

Your explanation should connect AI use to the actual web project.

Be ready to discuss:

* HTML structure: what elements organize the page and content
* CSS layout: how the page is styled and arranged
* responsive design: how the page works at different screen sizes
* JavaScript behavior: what actions, events, or functions control the page
* data or state: what information changes, where it lives, and whether it persists
* validation or security awareness: how input, output, or user actions are handled
* testing: how you know the feature works

You do not need to use all of these categories, but you should be able to explain the ones that apply to your project.

## If You Did Not Use AI

If you did not use AI for the capstone, you may state:

> I did not use AI assistance for this capstone project.

You should still be ready to explain how you built, tested, and refined the project.

## Final Reminder

AI use is not automatically a problem.

Unexplained AI use is a problem.

Responsible AI use means you can describe what happened, show what changed, verify that it works, and explain why the final project is yours.
