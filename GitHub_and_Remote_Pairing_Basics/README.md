# GitHub And Remote Pairing Basics

Reusable bonus lecture module for 10-152 courses.

## Purpose

This folder contains optional recorded lecture sources and student support
artifacts for:

- GitHub basics for code submission
- remote paired programming in Zoom
- beginner-safe code sharing without advanced Git workflows

GitHub is treated as the primary location for code submitted for grading.
Schoology may still be used to submit a link, confirmation message, exported
PDF, or other instructor-requested item.

## Artifacts

- `GitHub_Basics_For_Code_Submission_Lecture_Deck_Source.md`
  - Reusable lecture deck source for account, repository, upload, download,
    README, and submission basics.
- `Remote_Paired_Programming_Lecture_Deck_Source.md`
  - Reusable lecture deck source for paired/group programming through Zoom.
- `Remote_Pairing_And_GitHub_Checklist.md`
  - One-page-ish student checklist for live use during remote work.
- `GitHub_And_Remote_Pairing_Image_Prompts.md`
  - Browser-based ChatGPT image-generation prompts for the decks.

## Scope Boundary

This module is intentionally not a full Git/GitHub course.

It avoids:

- command-line Git
- branching and merging
- pull requests
- advanced conflict resolution
- professional team workflow depth

It focuses on beginner survival skills:

- create or open a repository
- organize files clearly
- upload updated work
- download current work
- avoid overwriting partners
- submit the correct GitHub link
