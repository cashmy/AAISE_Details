# GitHub And Remote Pairing Image Prompts

**Reusable Bonus Module**

---

# Purpose

This companion artifact provides browser-based ChatGPT image-generation prompts
for the GitHub Basics and Remote Paired Programming bonus decks.

Global style guidance:

- clean instructional PowerPoint visual
- white or very light background
- modern classroom-friendly style
- restrained SWTC-friendly colors: navy, teal, warm gold, white, soft gray
- large readable labels
- no dense code walls
- no dark hacker aesthetic
- no brand logos unless added manually later

---

# GitHub Basics Prompts

## GitHub Slide 1 - GitHub Is Where Your Code Lives

```text
Create a clean instructional PowerPoint visual showing GitHub as the place where course code lives.

Use a white or very light background. Show a simple repository cabinet with organized lab folders and code files. Add labels:

- store code
- submit for grading
- preserve progress

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid dense code, hacker imagery, or official logos.
```

## GitHub Slide 5 - Lab Folder Pattern

```text
Create a clean instructional PowerPoint visual showing a beginner lab folder structure.

Use a white or very light background. Show one repository containing three lab folders. Each lab folder contains README.md and code files.

Add a large reminder:
"One lab, one folder."

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid tiny file trees or dense technical detail.
```

## GitHub Slide 8 - Downloading Code

```text
Create a clean instructional PowerPoint visual showing the beginner process for downloading code from GitHub.

Use a white or very light background. Show a simple six-step path:

1. open repository
2. click Code
3. download ZIP
4. extract ZIP
5. open folder
6. run or preview

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid official screenshots, dense UI detail, or command-line imagery.
```

## GitHub Slide 10 - Uploading Updated Files

```text
Create a clean instructional PowerPoint visual showing the beginner process for uploading changed files to GitHub.

Use a white or very light background. Show a simple path:

open repository -> Add file -> Upload files -> short message -> Commit changes -> confirm files

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid official screenshots, command-line Git, or advanced branching imagery.
```

## GitHub Slide 12 - Submitting For Grading

```text
Create a clean instructional PowerPoint visual showing GitHub as the source of code for grading.

Use a white or very light background. Show a repository link moving to a grading/submission inbox. Include a small Schoology-style placeholder box only as "submit link here" without using a logo.

Add labels:

- code in GitHub
- link submitted for grading
- latest files visible

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid official logos, dense UI, or confusing multiple submission paths.
```

## GitHub Slide 14 - Avoid Overwriting Work

```text
Create a clean instructional PowerPoint visual warning students not to overwrite partner work.

Use a white or very light background. Show two separate file copies converging toward one repository with a pause sign before upload. Add labels:

- ask first
- download latest
- keep backup
- do not overwrite silently

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid scary warning imagery, red alarm design, or advanced merge diagrams.
```

# Remote Pairing Prompts

## Pairing Slide 1 - Structured Collaboration

```text
Create a clean instructional PowerPoint visual showing remote paired programming as structured collaboration.

Use a white or very light background. Show two student workstations connected through a video call window and one shared code/project area. Add labels:

- shared understanding
- talk through decisions
- both can explain

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid distracting faces, brand logos, or dark hacker imagery.
```

## Pairing Slide 4 - Driver And Navigator

```text
Create a clean instructional PowerPoint visual explaining driver and navigator roles.

Use a white or very light background. Show two side-by-side role cards:

Driver:
- shares screen
- controls keyboard
- types changes

Navigator:
- reads requirements
- watches logic
- asks questions

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid implying one role is more important than the other.
```

## Pairing Slide 5 - Groups Of Three

```text
Create a clean instructional PowerPoint visual showing three remote collaboration roles.

Use a white or very light background. Show three role cards:

- Driver
- Navigator
- Checker

Connect them around a shared assignment/project card. Add a small reminder:
"Rotate every 10-15 minutes."

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid hierarchy, clutter, or official app logos.
```

## Pairing Slide 6 - Remote Setup In Zoom

```text
Create a clean instructional PowerPoint visual showing a remote coding setup.

Use a white or very light background. Show a shared screen area, assignment instructions panel, code editor panel, and small chat/link area. Add labels:

- share screen
- keep requirements visible
- say changes out loud

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid official Zoom logos, cluttered screenshots, or tiny UI details.
```

## Pairing Slide 10 - Test Before Changing More

```text
Create a clean instructional PowerPoint visual showing the pair programming rhythm.

Use a white or very light background. Show a circular flow:

choose small change -> say plan -> make change -> test -> explain -> continue

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid dense code, speed imagery, or chaotic multitasking visuals.
```

## Pairing Slide 15 - AI During Pair Work

```text
Create a clean instructional PowerPoint visual showing AI as a support during pair work, not a replacement for discussion.

Use a white or very light background. Show two students reviewing one AI explanation card together beside their own code/project card. Add labels:

- both read
- both discuss
- both test
- both understand

Use restrained navy, teal, warm gold, white, and soft gray.

Avoid robots, AI writing code alone, magic imagery, or dark AI visuals.
```
