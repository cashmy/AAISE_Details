# Assignment Success Examples

This folder contains instructor-facing successful examples for Python course assignments.

These files are not demo scripts and should not be treated as student starter code.

They are intended to help the instructor:

* calibrate assignment expectations
* verify that assignment requirements are realistic
* develop grading examples
* prepare feedback language
* identify possible scaffolding needs before students submit work

The examples should be different from the instructor demos so students are not shown near-solutions to the same task.

## Naming Pattern

```text
##_Assignment_Title_success.py
##_Assignment_Title_notes.md
```

Use `.md` files when a successful submission requires explanation, reflection, debugging notes, or other written evidence.
