A good sequence would be:

1. Draft all assignment artifacts.
2. Sanity-check each against the MRS mapping and IIM.
3. Create instructor demo code examples.
4. Create one or more “successful student submission” examples per assignment or per option group.
5. Use those examples to revise assignment requirements.
6. Create starter code only where it helps and does not undermine the learning target.

The key distinction:

* Demo code teaches the concept and should be slightly different from the assignment.
* Successful assignment examples validate that the assignment is doable and appropriately scoped.
* Starter code scaffolds student work and should be used carefully, especially early.

Recommendation for this course:

* continue drafting assignments 5-16 first
* after every 4 assignments, generate aligned demo/success examples for that batch
* then revise that batch before moving too far downstream
