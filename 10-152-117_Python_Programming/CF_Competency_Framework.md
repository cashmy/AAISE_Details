# 🔹 Competency Framework (CF-01)

## 📘 Python Programming (Basics) — Competencies

---

## **1. Analyze problems and define program logic**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Break problems into step-by-step logic
* Identify inputs, outputs, and constraints
* Represent solutions using structured logic (pseudocode or code)
* Distinguish between clear and ambiguous problem statements

### Learning Objectives

* Define program logic and problem decomposition
* Identify inputs, outputs, and constraints
* Describe step-by-step problem-solving approaches

---

## **2. Implement Python programs using core programming constructs**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Write Python programs using variables, data types, conditionals, and loops
* Use lists and dictionaries to manage data
* Define and use functions
* Apply basic file input/output operations
* Produce readable and structured code

### Learning Objectives

* Identify Python syntax and constructs
* Explain variables, data types, and control structures
* Describe functions and basic data structures

---

## **3. Utilize AI-assisted tools to develop and refine Python programs**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Use AI tools to generate or assist in writing code
* Provide clear prompts that describe the intended solution
* Modify and adapt AI-generated code to meet requirements
* Integrate AI-generated components into working programs

### Learning Objectives

* Describe how AI tools support programming
* Identify effective prompting strategies
* Explain how to adapt generated code

---

## **4. Evaluate and debug Python programs for correctness and clarity**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Identify and fix syntax and logical errors
* Test programs using sample inputs
* Explain how a program works step-by-step
* Compare different approaches to solving the same problem

### Learning Objectives

* Define debugging and testing
* Identify common programming errors
* Explain program execution flow

---

## **5. Adapt programming approaches with and without AI assistance**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Write basic programs without relying on AI tools
* Use AI to improve or extend existing solutions
* Explain their code to others clearly
* Adjust solutions based on constraints or requirements

### Learning Objectives

* Describe differences between manual and AI-assisted development
* Explain when AI use is appropriate
* Identify strategies for adapting solutions
