# 5. Core Concepts (10-20 minutes)

## Concept 1 - Numbers are values too

Plain-language explanation:

* Python can store numbers just like it stores text
* numbers can participate in expressions

Why it matters:

* Assignment 1 options like converters and cost estimators depend on numeric values

## Concept 2 - Expressions create new values

Plain-language explanation:

* an expression combines values using operators such as `+`, `-`, `*`, and `/`
* the result can be stored or printed

Why it matters:

* students must understand that the output often comes from a calculation, not from a fixed line of text

## Concept 3 - Value flow matters

Plain-language explanation:

* a value starts somewhere
* it may be stored in a variable
* it may be used in an expression
* it becomes output

Why it matters:

* the course depends heavily on tracing values through code

## Concept 4 - Optional `input()` as a beginner tool

Plain-language explanation:

* `input()` can collect a user response
* if used today, it should stay simple and controlled

Why it matters:

* some Assignment 1 options may benefit from it
* but comprehension matters more than novelty

# 8. Common Mistakes / Watch-Fors (5-8 minutes)

## Mistake 1 - losing track of where the value came from

Why it happens:

* students see several variables and stop tracing the flow

Correction:

* keep asking: where did this value start, and where did it go?

## Mistake 2 - mixing explanation with memorization

Why it happens:

* students may try to remember symbols without understanding what changed

Correction:

* ask them to narrate the calculation in plain language

## Mistake 3 - `input()` overwhelms the concept

Why it happens:

* student attention shifts to typing and syntax rather than value flow

Correction:

* use `input()` only if it supports understanding rather than replacing it

---

# 9. Explain / Checkpoint Questions (3-8 minutes)

Ask:

* What value started in this variable?
* What expression changed that value?
* What is printed at the end?
* If I change the starting number, what changes later?
* If `input()` is used: what does the user response become inside the program?

---

# 10. End-of-Class Success Check

> By the end of this session, students should be able to store numeric values, use simple expressions, print the result, and trace how a value moved from one step of the program to the next.
