# 3. Opening Frame (2-4 minutes)

**Goal:** orient students immediately

Include:

* what the session is about
* why it matters
* how it connects to the current week

Suggested stem:

> "Today we are moving from ______ to ______."

---

# 4. Course Positioning (2-4 minutes)

**Goal:** place the lesson in the larger course arc

Include:

* what students have already learned
* what this session adds
* what this session prepares them to do next

Suggested stem:

> "So far, you have worked with ______. Today we add ______ so that you can later ______."

---

# 5. Core Concepts (10-20 minutes)

**Goal:** teach only what is needed for assignment readiness

List `3-5` concepts maximum.

For each concept, include:

* concept name
* plain-language explanation
* why it matters for the assignment

Guideline:

* if it does not support the readiness target, it probably does not belong in this lecture

---

# 6. Demo Plan (10-20 minutes)

**Goal:** make the concepts visible and concrete

For each demo, include:

* file or artifact name
* what the demo shows
* what students should notice

Guideline:

* keep demos small
* prefer contrast when useful
* explicitly say what the demo is proving

---

# 7. Hands-On / Lab Bridge (10-20 minutes)

**Goal:** connect lecture to immediate student action

Include:

* what students should try today
* what they are not expected to master yet
* where the assignment begins or progresses

Suggested stem:

> "Your goal today is not ______. Your goal is to ______."

---

# 8. Common Mistakes / Watch-Fors (5-8 minutes)

**Goal:** prevent predictable frustration

List `2-4` likely errors or misunderstandings.

For each one, include:

* what students may do
* why it happens
* how you will frame or correct it

---

# 9. Explain / Checkpoint Questions (3-8 minutes)

**Goal:** verify readiness before students leave the session

Include a small set of prompts such as:

* "What does this line do?"
* "Why did this branch run?"
* "Where is this value stored?"
* "What changed from input to output?"

These should connect directly to the readiness target.

---

# 10. End-of-Class Success Check

Complete the sentence:

> "By the end of this session, students should be able to ______."

This should match the readiness target closely.

# Use Guidance

## Do

* keep the outline tightly aligned to readiness
* use the demo set intentionally
* name assumptions explicitly
* preserve the session micro-arc

## Do Not

* turn one lecture into a textbook dump
* introduce concepts just because they are adjacent
* assume students know a concept that has not been directly modeled
