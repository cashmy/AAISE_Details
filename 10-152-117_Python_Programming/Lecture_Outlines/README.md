# How to Use

## For Lecture Delivery

Use the day-specific outline directly.

The most important sections for live teaching are:

* Alignment Anchor
* Core Concepts
* Demo Plan
* Hands-On / Lab Bridge
* End-of-Class Success Check

## For Slide-Deck Drafting

Use the outline as the source logic artifact.

Do not convert the outline directly into slide paragraphs.

Instead:

* extract the core anchor ideas
* preserve the readiness target
* preserve the day's watch point
* preserve the demo emphasis
* preserve the hands-on bridge

## For Future Revision

Revise through the alignment artifacts first when possible.

That keeps the governance flow intact:

* alignment matrix
* lecture outline
* slide deck

# System Value

This lecture-outline set is meant to do more than describe content.

It helps keep instruction aligned to:

* what students need before assignments launch
* what demos support readiness
* what assumptions must be made explicit
* what kinds of overload or drift should be prevented
