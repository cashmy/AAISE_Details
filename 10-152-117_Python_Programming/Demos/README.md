# Python Course Demos

This folder contains instructor demo materials for `10-152-117 Python Programming`.

## Organization

Demos are organized by week:

```text
Demos/
  Week_01_First_Programs_and_Basic_Values/
    01_demo_name.py
    02_demo_name.py
```

## Naming Pattern

Use:

```text
##_short_descriptive_name.py
```

Examples:

* `01_print_strings_variables.py`
* `02_numbers_expressions.py`
* `03_input_optional.py`

## Use

These files are instructor-facing examples.

They are meant to support lecture and guided demonstration. They should be similar to, but not identical to, student assignment solutions.

Some weeks may include `.md` walkthrough files when the demo is conceptual rather than executable.

## Instructor Notes

Instructor notes are broader teaching narratives that support the demos:

* `Instructor_Notes-Typing_vs_CopyPaste.md`
* `Instructor_Notes-Debugging_Process.md`
