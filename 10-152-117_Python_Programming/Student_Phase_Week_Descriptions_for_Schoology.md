# Student Phase & Week Descriptions — Python Programming

---

# Course Overview

This course is designed to help you learn Python in a way that is structured, manageable, and practical.

You will begin with core programming basics, then move into organizing code, working with data, and building small programs that solve real problems. Later in the course, you will apply what you have learned in a capstone project that you design and build with instructor approval.

The course is organized into phases so you can always see where you are in the larger learning process. Each week also has a clear theme so that the work feels connected rather than random.

---

# Phase 1 — Foundations + Manual Habits

In this phase, you will learn the basics of how Python programs work.

You will focus on writing small programs, working with values, making decisions, and using repetition. The goal is to help you build confidence and develop real understanding before adding more complexity.

This phase is intentionally manual-first. You will spend time writing, tracing, fixing, and explaining your own code so that you build a strong foundation.

---

## Week 1 — First Programs and Basic Values

This week, you will begin writing your first Python programs.

You will learn how programs display output, store values, and use simple variables and expressions. You will also begin learning how to read code line by line and explain what it is doing.

The goal this week is to make Python feel approachable and to help you create your first working programs successfully.

---

## Week 2 — Decision Logic and Repetition

This week, you will learn how programs make choices and repeat actions.

You will work with conditionals and loops to create programs that respond differently based on input and can repeat steps when needed.

The goal this week is to help you move from simple scripts to programs that have real logic and flow.

---

# Phase 2 — Structure + Code Literacy

In this phase, you will begin organizing your code more intentionally.

You will learn how to break programs into parts, manage information more effectively, and read code in different forms. You will also strengthen your debugging and explanation skills.

The goal is to move from "I can make it work" toward "I can understand, organize, and improve it."

---

## Week 3 — Organizing Code and Data

This week, you will learn how to organize logic and store information in more useful ways.

You will work with functions, lists, and dictionaries so that your programs can become more structured and easier to manage.

The goal this week is to help you write programs that are not only correct, but also easier to read and extend.

---

## Week 4 — Debugging, Testing, and Reading Structured Code

This week, you will focus on understanding code more deeply.

You will practice debugging, basic testing, and explaining how code works. You will also begin reading simple structured code examples, including class-based code, so you can recognize different ways programs may be organized.

The goal this week is to build confidence when code becomes more complex or when something does not work as expected.

---

# Phase 3 — Data, Files, and Bounded AI Support

In this phase, you will begin working with data that goes beyond simple in-memory programs.

You will learn how programs save information, use structured data, and interact with outside sources such as files and APIs. You will also begin using AI support more deliberately and responsibly when allowed.

The goal is to help you see Python as a tool for building more practical and connected programs.

---

## Week 5 — Files, Errors, and Data Persistence

This week, you will learn how programs save, load, and manage information over time.

You will work with files, basic error handling, and simple structured data formats such as CSV or JSON. You will also begin to see that larger applications organize data in more structured ways than simple files alone.

The goal this week is to help you build programs that can store information, recover it later, and respond more responsibly when problems occur.

---

## Week 6 — APIs, External Data, and Python App Architecture

This week, you will learn how Python programs can connect to information outside the program itself.

You will work with APIs, requests, responses, and JSON data in a practical, beginner-friendly way. You will also be introduced to the idea that Python can appear in larger application structures, including web-based systems. At the same time, you will continue learning how to use AI responsibly as a support tool rather than as a replacement for understanding.

The goal this week is to help you use outside data while still making thoughtful decisions about structure, correctness, and explanation.

---

# Phase 4 — RBA Mini-Unit + Capstone Application

In this phase, you will prepare for and complete your capstone project.

You will be introduced to a project-development framework called Refraction-Based Architecture in a bounded way, then apply that thinking to project planning, revision, and explanation. You will use what you have learned throughout the course to build a project that is both functional and understandable.

The goal is to help you move from completing guided tasks to building and explaining a project of your own.

---

## Week 7 — RBA and Project Framing

This week, you will learn how to frame a project more deliberately before building it.

You will focus on defining purpose, inputs, outputs, constraints, and likely structure before moving into implementation. You will also make key decisions about project scope and direction so your capstone is realistic and well planned.

The goal this week is to help you think more clearly about what you are building and why.

---

## Week 8 — Capstone Build, Justification, and Presentation

This week, you will complete and present your capstone project.

You will use the Python skills, debugging habits, and structured thinking you developed earlier in the course. You will also explain how your project works, how you tested it, and how you used AI support if it was part of your process.

The goal this week is to show that you can build something meaningful, explain your choices clearly, and demonstrate ownership of your final work.

---

# Final Throughline

By the end of this course, you should be able to:

* write and explain basic Python programs
* organize and debug your code more effectively
* work with files, structured data, and basic external data
* use AI support responsibly when allowed
* build and present a small project that demonstrates what you have learned

This course is designed to help you grow step by step. Each phase builds on the one before it, and each week moves you closer to creating, understanding, and explaining your own programs.
