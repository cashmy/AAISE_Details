# ASSIGNMENT 5 — LIST OR DICTIONARY MINI-APP

**Week 3 — Organizing Code and Data**

---

# Context

Programs often need to remember more than one value.

Lists and dictionaries help you store, retrieve, and organize related information. In this assignment, you will build a small program that uses a collection to manage data.

The goal is to create a small tool that feels more useful than a single-purpose script.

---

# Objective

Create a small Python mini-app that uses a list or dictionary to store and work with data.

Your program should demonstrate:

* a list and/or dictionary
* storing and retrieving values
* iteration over a collection
* readable organization

---

# Task

Build one small collection-based mini-app.

Possible options include:

* score tracker
* item lookup tool
* simple task list
* menu selector
* contact or inventory lookup

Your instructor may assign a specific option or approve your choice.

---

# Requirements

Your program should:

* use at least one list or dictionary
* add, access, display, or update stored data
* use a loop to process or display collection items
* use readable variable names
* run without syntax errors

Functions may be used if they help organize the program.

---

# AI Use

Limited AI comparison or revision may be allowed only after you have a working manual version or a clear manual plan.

If AI is allowed, you must be able to explain what the AI suggested and what you kept, changed, or rejected.

---

# Submission Requirements

Submit your `.py` file as instructed.

Your submission should include:

* one working Python file
* a list or dictionary used meaningfully
* visible output
* code that is readable and explainable

---

# Reflection / Explanation

Answer briefly:

> What collection did you use, and how did it help your program manage information?

If you used AI:

> What did AI suggest, and what did you keep, change, or reject?
