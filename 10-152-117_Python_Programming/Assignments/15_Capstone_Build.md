# ASSIGNMENT 15 — CAPSTONE BUILD

**Week 8 — Capstone Build, Justification, and Presentation**

---

# Context

This assignment is the main build phase for your approved capstone project.

You will apply Python concepts from across the course to create a small, working project that you can explain clearly.

---

# Objective

Build your approved capstone project.

Your project should demonstrate:

* appropriate Python fundamentals
* useful logic and structure
* data handling when relevant
* debugging and validation
* accountable AI use if AI is used

---

# Task

Complete the approved capstone project according to your proposal and instructor feedback.

Your project may be:

* console-based
* data-driven
* API-based
* light UI/web-architecture preview based, if approved
* another approved Python project style

---

# Requirements

Your capstone should:

* match the approved scope or approved revision
* run successfully
* include readable, organized code
* demonstrate multiple course concepts
* include testing or validation evidence
* remain explainable by you

---

# AI Use

Strategic AI use is allowed with accountability.

If you use AI, you must:

* keep the project aligned to your approved intent
* inspect and test generated code
* adapt or reject suggestions when needed
* be ready to explain what AI helped with and what decisions remained yours

---

# Submission Requirements

Submit as instructed:

* project code files
* any required data files
* brief run instructions if needed
* testing or validation notes if requested

---

# Reflection / Explanation

Answer briefly:

> What is the most important part of your project, and how did you verify that it works?

If you used AI:

> What did AI help with during the build, and what did you change, reject, or decide yourself?
