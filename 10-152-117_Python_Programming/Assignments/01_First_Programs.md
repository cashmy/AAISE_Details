# ASSIGNMENT 1 — FIRST PROGRAMS

**Week 1 — First Programs and Basic Values**

---

# Context

This assignment is your first step into writing Python programs.

The goal is not to build something large or complex. The goal is to get comfortable writing small programs, running them, seeing output, and explaining what each line does.

You will practice using values, variables, strings, numbers, and simple input/output.

---

# Objective

Create a small set of Python programs that demonstrate:

* visible output
* variables
* strings and numbers
* simple expressions
* basic input/output flow, if introduced in class

---

# Task

Create `2-3` very small Python programs.

Possible program options include:

* greeting or introduction program
* simple calculator
* unit converter
* total-cost estimator
* personalized message builder

Your instructor may provide specific options or allow you to choose from the list.

---

# Requirements

Your programs should:

* run without syntax errors
* use clear variable names
* display output using `print()`
* use strings and/or numeric values
* include simple expressions or value changes
* be easy to read and explain

If `input()` has not yet been introduced, use assigned variables in your code instead of asking the user for input.

If `input()` has been introduced, at least one program should accept simple user input.

---

# AI Use

AI is not allowed for normal work on this assignment unless the instructor explicitly says otherwise.

This assignment is manual-first so you can build confidence with the basic mechanics of Python.

---

# Submission Requirements

Submit your Python file or files as instructed.

Your submission should include:

* `.py` file or files
* clear filenames
* code that runs without errors
* short comments only if they help explain your thinking

---

# Reflection / Explanation

Answer briefly:

> Pick one of your programs. What values does it use, and how does the program turn those values into output?

---

# Instructor Notes

This assignment should remain small and confidence-building.

Watch for students being overloaded by `input()` too early. If input has not been fully introduced, allow hardcoded variable assignment instead.

The key learning target is value flow:

> value exists → variable stores it → expression uses it → output displays it
