# ASSIGNMENT 8 — SAVE AND LOAD UTILITY

**Week 5 — Files, Errors, and Data Persistence**

---

# Context

Programs become more useful when they can remember information after they stop running.

In this assignment, you will build a small utility that saves information and loads it later.

---

# Objective

Create a Python program that uses file input/output to persist data.

Your program should demonstrate:

* writing data to a file
* reading data from a file
* basic error handling
* clear explanation of what is being saved and loaded

---

# Task

Build a small save/load program.

Possible options include:

* note keeper
* task list
* simple tracker
* saved preferences file
* stored score or progress file

Your instructor may assign a specific option or approve your choice.

---

# Requirements

Your program should:

* write data to a file
* read data from a file
* show the loaded data clearly
* handle at least one likely file-related problem
* run without syntax errors

Your instructor may specify text, CSV, or JSON depending on class progress.

---

# AI Use

Bounded AI support may be allowed after manual work has begun.

If AI is allowed, it may be used to compare file-handling patterns or improve error messages. You must still explain how saving and loading work.

---

# Submission Requirements

Submit as instructed:

* `.py` file
* any required sample data file
* brief explanation of save/load behavior

---

# Reflection / Explanation

Answer briefly:

> What information does your program save, where is it stored, and how does the program load it again?

If you used AI:

> What file-handling support did AI provide, and what did you change or verify?
