# ASSIGNMENT 7 — READING STRUCTURED CODE

**Week 4 — Debugging, Testing, and Reading Structured Code**

---

# Context

Not all code will be written in the same style.

AI-generated code and many professional examples often use class-based structures. You do not need to master object-oriented design in this course, but you do need to recognize and explain simple class-based code.

---

# Objective

Read, explain, and lightly modify a simple structured Python program.

Your work should demonstrate:

* code reading
* recognition of functions and classes
* basic explanation of attributes and methods
* comparison of different code organization styles

---

# Task

Inspect a simple class-based Python example and compare it with a procedural or function-based version of the same task.

You may be asked to:

* identify the class
* identify attributes
* identify methods
* instantiate an object
* call a method
* make a small modification

---

# Requirements

Your submission should:

* explain the purpose of the class or structure
* correctly identify key parts of the example
* make a small working modification
* compare the class-based version with a function-based or procedural version
* run without syntax errors

---

# AI Use

Bounded AI explanation support may be allowed.

You may use AI to help explain unfamiliar structure only if you still verify the explanation against the code and can restate it in your own words.

---

# Submission Requirements

Submit as instructed:

* modified `.py` file
* short explanation or worksheet responses

---

# Reflection / Explanation

Answer briefly:

> What did the class store, what did its methods do, and how was this different from a function-based version?

If you used AI:

> What explanation did AI provide, and how did you verify that it matched the code?

# Success Criteria

To succeed on this assignment:

* you should correctly identify the main parts of the structured code
* your modification should work
* your explanation should be in your own words
* you should understand the difference between organization styles at a beginner level

---

# Instructor Notes

This assignment is recognition and interpretation, not full OOP mastery.

Keep examples small. Avoid inheritance, polymorphism, or advanced magic methods.

The key learning target is:

> students should not freeze when AI or documentation returns class-based code.
