# ASSIGNMENT 11 — API DATA FETCHER

**Week 6 — APIs, External Data, and Python App Architecture**

---

# Context

Python programs can use information from outside the program itself.

APIs provide structured ways to request and receive data. In this assignment, you will retrieve or inspect external data and use selected values in a meaningful way.

---

# Objective

Create a small Python program that retrieves or works with API-style data.

Your program should demonstrate:

* request/response thinking
* JSON response interpretation
* selected value extraction
* validation of AI-assisted or example code when used

---

# Task

Build a small API data fetcher using an approved public API, controlled endpoint, or instructor-provided simulated response.

Possible options include:

* weather lookup
* public facts or lookup data
* simple open-data endpoint
* simulated JSON response if live API access is not appropriate

---

# Requirements

Your program should:

* retrieve or load API-style JSON data
* access specific values from the response
* display selected information clearly
* avoid printing only raw JSON
* handle at least one likely problem when appropriate
* run without syntax errors

---

# AI Use

Bounded implementation support may be allowed.

If AI is used, you must validate the generated code, inspect the response structure, and explain what human decisions were still required.

---

# Submission Requirements

Submit as instructed:

* `.py` file
* any notes about the API or simulated data source
* brief explanation of the request/response flow

---

# Reflection / Explanation

Answer briefly:

> What data did your program retrieve or inspect, and how did you choose which values to display?

If you used AI:

> What did AI help scaffold, and how did you validate that the code worked?
