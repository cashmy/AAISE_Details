# ASSIGNMENT 4 — FUNCTION BUILDER

**Week 3 — Organizing Code and Data**

---

# Context

As programs grow, repeated code becomes harder to manage.

Functions help you organize logic into named, reusable parts. In this assignment, you will practice turning code into functions and explaining what each function is responsible for.

The goal is not just to make code work. The goal is to make code easier to understand.

---

# Objective

Create or refactor a small Python program that uses functions to organize logic.

Your program should demonstrate:

* function definitions
* function calls
* parameters and/or return values
* clearer structure than a single block of repeated code

---

# Task

Build or revise a small program so that important pieces of logic are placed into functions.

Possible options include:

* refactor an earlier calculator or converter
* create a small menu of reusable actions
* build a utility with separate input, processing, and output functions
* revise repeated conditional or loop logic into named functions

Your instructor may provide starter code or ask you to refactor one of your earlier programs.

---

# Requirements

Your program should:

* define at least `2` functions
* call each function correctly
* use meaningful function names
* avoid unnecessary repeated code
* run without syntax errors

At least one function should use a parameter or return a value, if those concepts have been introduced.

---

# AI Use

Limited AI comparison may be allowed only after you have a manual version or manual plan.

If AI is allowed by the instructor, you may use it to compare structure or suggest a refactor. You may not submit AI-generated code that you cannot explain.

---

# Submission Requirements

Submit your `.py` file as instructed.

Your submission should include:

* one working Python file
* at least `2` functions
* readable names
* clear output or visible behavior

---

# Reflection / Explanation

Answer briefly:

> What does each function in your program do, and how did functions make the program easier to understand?

If you used AI for comparison or refactoring, also answer:

> What did AI suggest, and what did you keep, change, or reject?

# Success Criteria

To succeed on this assignment:

* your program should use functions correctly
* each function should have a clear purpose
* your code should be easier to follow than one long block
* you should be able to explain how the functions work together

---

# Instructor Notes

This is the first assignment where code organization becomes a primary target.

Consider providing a rough version of code and asking students to improve structure, especially if students are struggling to identify where functions should go.

The key learning target is:

> repeated or related logic can be named, separated, reused, and explained
