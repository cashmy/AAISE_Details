# ASSIGNMENT 9 — STRUCTURED DATA READER

**Week 5 — Files, Errors, and Data Persistence**

---

# Context

Many programs work with structured data instead of plain text.

In this assignment, you will read provided structured data and turn it into useful output.

---

# Objective

Create a Python program that reads CSV or JSON data and produces a meaningful result.

Your program should demonstrate:

* reading structured data
* accessing specific fields or values
* filtering, summarizing, or formatting data
* explaining how the data is organized

---

# Task

Use a provided CSV or JSON file.

Your program should produce one useful output, such as:

* filtered list
* summary count
* selected record display
* simple report
* formatted data view

---

# Requirements

Your program should:

* read the provided structured data file
* access specific values rather than printing raw data only
* produce readable output
* handle at least one likely data or file issue when appropriate
* run without syntax errors

---

# AI Use

Bounded AI comparison may be allowed.

If AI is allowed, you may use it to compare parsing approaches or clarify data structure. You must still explain how your program accesses the data.

---

# Submission Requirements

Submit as instructed:

* `.py` file
* provided or required data file, if requested
* brief explanation of the data structure used

---

# Reflection / Explanation

Answer briefly:

> What kind of structured data did you read, and how did your program select or summarize useful information from it?

If you used AI:

> What did AI help explain or compare, and how did you verify the result?

---

# Instructor Notes

Keep the data file small and predictable.

Students should not be expected to design a full data pipeline. The focus is reading, accessing, and explaining structured data.

The key learning target is:

> structured data has a shape, and programs must understand that shape to use it.
