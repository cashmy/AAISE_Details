# ASSIGNMENT 3 — LOOPS AND REPETITION

**Week 2 — Decision Logic and Repetition**

---

# Context

Programs often need to repeat actions.

In this assignment, you will build a small program that uses a loop to repeat behavior in a controlled way.

The focus is on understanding when a loop starts, what happens each time it runs, and when it stops.

---

# Objective

Create a Python program that demonstrates repetition using a loop.

Your program should demonstrate:

* `for` or `while`
* repeated behavior
* a clear stopping point
* output that shows the loop is working

---

# Task

Build one small loop-based program.

Possible options include:

* counting program
* repeated-input collector
* simple menu loop
* number sequence generator
* practice quiz loop
* total accumulator

Your instructor may assign one option or approve your choice.

---

# Requirements

Your program should:

* use at least one loop
* repeat an action more than once
* stop in a clear and intentional way
* produce visible output
* run without syntax errors

If using a `while` loop, make sure the loop condition can eventually become false.

If using a `for` loop, make sure the range or collection being repeated over is clear.

---

# AI Use

AI is not allowed for normal work on this assignment unless the instructor explicitly says otherwise.

Loop logic should be practiced manually so you can learn how repetition works.

---

# Submission Requirements

Submit your `.py` file as instructed.

Your submission should include:

* one working Python file
* a loop that repeats intentionally
* clear output
* code that does not get stuck in an infinite loop

---

# Reflection / Explanation

Answer briefly:

> What repeats in your program, and how does your program know when to stop?
