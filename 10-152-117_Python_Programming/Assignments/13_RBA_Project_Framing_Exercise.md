# ASSIGNMENT 13 — RBA PROJECT FRAMING EXERCISE

**Week 7 — RBA and Project Framing**

---

# Context

Before building a project, you need to understand what you are trying to build and why.

This assignment introduces a bounded version of Refraction-Based Architecture as a project-framing process. The goal is to define intent, constraints, and structure before using AI or writing major code.

---

# Objective

Create a project framing document for a small Python project idea.

Your work should demonstrate:

* project intent
* inputs and outputs
* constraints
* possible structure
* AI-use boundaries

---

# Task

Frame a possible project before coding.

Your project idea may be for the capstone or for a smaller practice scenario.

You should identify:

* what the project is for
* who or what uses it
* what inputs it needs
* what outputs it produces
* what constraints matter
* what structure might fit
* where AI might help
* where AI should not make decisions for you

---

# Requirements

Your framing document should include:

* project purpose
* inputs
* outputs
* constraints
* likely program structure
* risks or unknowns
* AI-use boundaries

No full build is required for this assignment unless the instructor says otherwise.

---

# AI Use

Bounded AI support may be used only after you complete an initial manual framing attempt.

AI may help you identify options or risks, but it should not decide the project purpose or scope for you.

---

# Submission Requirements

Submit your project framing sheet or document as instructed.

Your submission should be clear enough that another person can understand what you intend to build.

---

# Reflection / Explanation

Answer briefly:

> What did you clarify before coding that would have been easy to skip?

If you used AI:

> What did AI help surface, and what decision remained yours?

# Instructor Notes

This assignment should produce a usable framing artifact, not a philosophical essay.

Push students toward concrete scope and away from vague ambition.
