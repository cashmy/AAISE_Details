# ASSIGNMENT 10 — DATA REPRESENTATION AND APP-STRUCTURE PREVIEW

**Week 5 — Files, Errors, and Data Persistence**

---

# Context

So far, you have worked with data in variables, collections, files, CSV, and JSON.

Larger applications often organize data in more formal ways. This assignment gives you a preview of how the same information can be represented in different structures.

This is a recognition-level assignment, not a full database or framework project.

---

# Objective

Compare different ways data can be represented and explain how application data may become more structured.

Your work should demonstrate:

* recognition of data representation choices
* comparison of flat files, structured data, and model-like structures
* beginner-level understanding of where ORM, relational data, or non-relational data may fit

---

# Task

Inspect a small example of the same information represented in multiple ways.

Examples may include:

* plain text
* CSV
* JSON
* dictionary/list structure
* model-like object or class
* simple database-style table representation

You will compare the examples and explain how the representation affects use.

---

# Requirements

Your response should:

* identify at least `2` different data representations
* explain what is easier or harder about each representation
* identify where a larger application might need more structure
* use correct beginner-level vocabulary

If a small code edit is included, it should be guided and limited.

---

# AI Use

AI may be used as a bounded explainer.

You may ask AI to help explain unfamiliar terms, but you must restate the ideas in your own words and connect them to the examples provided.

# Submission Requirements

Submit as instructed:

Answer briefly:

> What changed when the same information was represented in a different structure?
