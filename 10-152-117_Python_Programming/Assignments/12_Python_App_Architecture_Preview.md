# ASSIGNMENT 12 — PYTHON APP ARCHITECTURE PREVIEW

**Week 6 — APIs, External Data, and Python App Architecture**

---

# Context

Python is not limited to console programs and scripts.

Python can also be used inside larger application structures, including web applications. This assignment gives you a recognition-level preview of how Python may support UI-driven systems.

This is not a full Django or framework-building assignment.

---

# Objective

Inspect a simple Python web-app flow and explain how the pieces fit together.

Your work should demonstrate recognition of:

* Python beyond console scripts
* MVT-style organization
* templates
* forms
* views or request handling

---

# Task

Inspect a guided example of a simple Python web-app architecture.

You may be asked to identify:

* where user input enters the system
* where form handling occurs
* where a view or controller-like function lives
* where a template displays output
* how data moves through the flow

Your instructor may include a small guided edit if appropriate.

---

# Requirements

Your response should:

* identify the main parts of the example
* explain the basic flow in plain language
* distinguish this structure from a console-only Python script
* complete any guided edit if assigned
