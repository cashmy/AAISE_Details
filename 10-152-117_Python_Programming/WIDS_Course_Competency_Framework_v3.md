# Course Competency Framework

## Course Information

**Course Title:** Python Programming  
**Course Number:** 10-152-117  
**Credits:** 2  
**Lecture Hours:** 18  
**Lab Hours:** 36  
**Total Hours:** 54  
**Instructional Level:** 10  

---

## Description

Learners explore Python programming by designing and implementing solutions to real-world problems. Students develop foundational programming skills using variables, data types, conditionals, loops, functions, and data structures. The course emphasizes problem-solving, debugging, and code comprehension while introducing the use of AI-assisted tools to support development. Learners practice building, evaluating, and refining programs, both independently and with AI assistance. By the end of the course, students are able to create, understand, and explain basic Python programs and apply structured thinking to solve problems.

---

## Framework Design Note

This version expands the WIDS Course Competency Framework to create a direct one-to-one relationship with the Master Rubric System (MRS). The first six competencies align to the course-specific technical rubric categories (T1-T6). The final six competencies align to the cross-course core ability rubric categories (C1-C6).

This structure supports the institutional requirement of three competencies per credit while also making the competency-to-rubric relationship easy to recognize for non-technical reviewers.

## 1. Apply Python fundamentals to construct working programs

**MRS Mapping:** T1. Python Fundamentals  
**Domain:** Cognitive  
**Level:** Applying  
**Status:** WIP  

### Assessment Strategies

* Lab-based programming assignments
* Project assignments
* Concept quizzes

### Criteria

Learners will be successful when they are able to:

* Write Python statements using correct syntax
* Use variables, values, expressions, and basic data types appropriately
* Apply input and output operations in simple programs
* Interpret and correct basic syntax or type-related issues
* Produce readable code that runs as intended

### Learning Objectives

* Identify Python syntax, values, variables, and expressions
* Explain how basic data types are used in Python programs
* Describe how input and output support program interaction

# Course Alignment Notes

This course introduces foundational programming skills and establishes patterns for AI-assisted development, problem-solving, code evaluation, communication, and professional technical conduct. The 12-competency structure creates a direct relationship between WIDS course competencies and the Master Rubric System, making the framework easier to audit, easier to maintain, and easier to reuse across related courses.
