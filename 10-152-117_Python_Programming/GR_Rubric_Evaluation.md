# 📘 Python Programming (Basics) — Evaluation System (GR-01 / AMM-01)

---

# 🔹 PART 1 — STANDARD LAB RUBRIC (USED EVERY WEEK)

Keep this consistent. Students should *learn the rubric* quickly.

---

## 🔹 Category 1 — Problem Understanding (20%)

**Exceeds (A)**

* Clearly explains what the program does
* Correctly identifies inputs and outputs
* Shows clear intent before coding

**Meets (B)**

* Basic understanding with minor gaps

**Developing (C)**

* Partial or unclear understanding

**Needs Improvement (D/F)**

* Does not demonstrate understanding

---

## 🔹 Category 2 — Working Program (25%) ⭐

*(Slightly higher weight for beginners)*

**Exceeds**

* Program runs correctly
* Handles expected inputs well
* Code is readable and organized

**Meets**

* Mostly works, minor issues

**Developing**

* Partially works, logic gaps

**Needs Improvement**

* Does not run or is incomplete

---

## 🔹 Category 3 — AI Usage (15%)

**Exceeds**

* Uses AI intentionally
* Modifies and improves generated code
* Shows clear input (prompting)

**Meets**

* Uses AI correctly but minimally

**Developing**

* Over-reliance on AI
* Limited understanding

**Needs Improvement**

* Direct copy with no awareness

---

## 🔹 Category 4 — Explanation & Understanding (25%) ⭐

*(Most important category alongside working code)*

**Exceeds**

* Clearly explains how code works
* Can walk through logic step-by-step

**Meets**

* General understanding with some gaps

**Developing**

* Limited explanation ability

**Needs Improvement**

* Cannot explain code

---

## 🔹 Category 5 — Effort & Improvement (15%)

*(Confidence protection category)*

**Exceeds**

* Shows iteration and improvement
* Attempts enhancements

**Meets**

* Completes required work

**Developing**

* Minimal effort or incomplete work

**Needs Improvement**

* Little to no attempt

# 🔹 PART 3 — QUIZ MODEL (LIGHTWEIGHT)

---

## 🔹 Purpose:

* reinforce concepts
* check understanding
* reduce memorization pressure

---

## 🔹 Types of Questions:

### 1. Concept Recognition

* “What does this loop do?”

### 2. Debug Thinking

* “What is wrong with this code?”

### 3. Prediction

* “What will this output?”

---

👉 Avoid:

* syntax trivia
* memorization-heavy questions

---

# 🔹 PART 4 — AI PROMPT GUIDELINES (STUDENT-FACING)

---

## 🔹 Basic Prompt Template (Weeks 1–4)

```text
I am trying to write a Python program that:
[describe problem]

Here is what I think the solution should do:
[their idea]

Can you generate a Python solution and explain it?
```

---

## 🔹 Intermediate Prompt (Weeks 5–8)

```text
Here is my code:
[paste code]

Can you:
- check if it is correct
- suggest improvements
- explain what could be better
```

---

## 🔹 Rule Reinforcement

> “Always tell AI what you are trying to do first.”
