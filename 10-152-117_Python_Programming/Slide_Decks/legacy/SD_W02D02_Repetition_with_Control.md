### SLIDE 1 - OPENING FRAME

Stop on purpose.

### SLIDE 3 - CORE IDEA

Ask what repeats.

---
Cue:
- This is the first thinking tool for loops.
- Keep attention on the repeated block, not the keyword only.

Visual:
- Layout: Isolated focus
- Content:
  - one loop snippet

- Purpose:
  - help students identify the repeated action clearly

### SLIDE 4 - CORE IDEA

Ask what changes.

---
Cue:
- This is the control idea that prevents confusion later.
- Especially important before or during `while` loop examples.

Visual:
- Layout: Flow
- Content:
  - loop cycle
  - state value changes after each cycle
- Purpose:
  - show that changing state drives progression and stopping

### SLIDE 5 - CORE IDEA

Ask what stops it.

---
Cue:
- This is the third core loop question.
- Use it to define the stopping condition explicitly every time.

Visual:
- Layout: Before / After
- Content:
  - condition true
  - condition false
- Purpose:
  - make the end of repetition visible and intentional

### SLIDE 6 - DEMO ANCHOR

Watch the update.

---
Cue:
- Use this before a `while` loop or accumulator demo.
- Ask students what becomes different after one loop cycle.

Visual:
- Layout: Flow
- Content:
  - current value

- Purpose:
  - direct attention to the part that often prevents infinite looping

### SLIDE 7 - COMMON FAILURE

Nothing changes.
Nothing ends.

---
Cue:
- This should land hard and memorable.
- Use it to preempt infinite-loop confusion.

Visual:
- Layout: Split contrast
- Content:
  - left: loop with no update
  - right: loop with state change
- Purpose:
  - show why a missing update is such a common failure
