### SLIDE 1 - OPENING FRAME

Values can change.
Output can change too.

---
Cue:

- Keep the emotional target small: one value changes, one result changes.

- Layout: Before / After
- Content:
  - left: one starting number
  - right: a changed printed result
- Purpose:
  - show that Python can transform values, not only display them

### SLIDE 3 - CORE IDEA

Numbers are values too.

---
Cue:
- Keep this plain and concrete.
- Say that Python stores numbers the same way it stores text: as values the program can use.

Visual:
- Layout: Split
- Content:
  - left: `"Hello"`
  - right: `42`
- Purpose:
  - show that different kinds of values can still be stored and used

### SLIDE 4 - CORE IDEA

Expressions make new values.

---
Cue:
- Emphasize that the result comes from the expression, not magic.
- Name the operators only as much as needed for today's work.

Visual:
- Layout: Flow
- Content:
  - `price`
  - `quantity`
  - `price * quantity`
  - printed total
- Purpose:
  - install the idea that computation transforms stored values

### SLIDE 5 - CORE IDEA

Visual:

### SLIDE 7 - COMMON FAILURE

Don’t lose the value.

---
Cue:
- Warn students that once several variables appear, they may stop tracing clearly.
- Keep returning to: where did this number come from?

Visual:
- Layout: Hierarchy
- Content:
  - chain of variables with one unclear step highlighted
- Purpose:
  - preempt the common failure of losing track of value origin
