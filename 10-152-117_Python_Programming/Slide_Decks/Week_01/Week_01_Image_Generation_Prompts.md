# Week 1 Image Generation Prompts

**10-152-117 Python Programming**

---

# Purpose

This companion artifact expands the compact `Image Prompt Notes` from the Week
1 v2 deck sources into more explicit image-generation prompts.

Use these prompts when PowerPoint Designer or manual layout does not provide a
clear enough visual.

Source decks:

- `SD_W01D01_What_a_Python_Program_Does_v2.md`
- `SD_W01D02_Values_Move_from_Input_to_Output_v2.md`
- `SD_W01D03_Putting_Basic_Values_Together_v2.md`

Global style guidance:

- clean instructional PowerPoint visual
- white or very light background
- modern, flat, classroom-friendly style
- large readable labels
- minimal decorative detail
- no complex IDE screenshots unless requested
- no dense code blocks
- no intimidating error imagery

# Week 1 Day 1 Prompts

## W01D01 Slide 1 - First Visible Success

```text
Create a clean instructional PowerPoint visual showing a student's first visible Python success.

Use a white or very light background. Show a simple split layout:

Left side: an empty or nearly empty code editor labeled "Before"
Right side: a terminal output panel labeled "After"

In the terminal output, show one friendly line:
"Welcome to class!"

Use a calm, beginner-friendly style. The visual should communicate that the first goal is simply making Python produce visible output.

Avoid complex IDE screenshots, tiny menus, dense code, dramatic lighting, or anything that suggests a large application.
```

## W01D01 Slide 2 - Course Growth Path

```text
Create a clean instructional PowerPoint visual showing how small Python programs grow into larger work over time.

Use a white or very light background. Show four connected blocks from left to right:

1. Tiny Program
2. Small Utility
3. Structured Program
4. Capstone Project

Use arrows between the blocks. Make the first block visibly small and approachable. Use simple Python-themed icons only if they remain subtle.

Add a small note:
"Start small. Build outward."

Avoid implying students are expected to build a large project now. No complex architecture diagrams, no app dashboard, no intimidating code.
```

## W01D01 Slide 4 - Today's Working Set

```text
Create a clean instructional PowerPoint visual showing today's beginner Python working set.

- variables

To the side, show a smaller "Later" tray with:

- input()

Make the included tools visually active and the "Later" tray calm and non-threatening.

Style should be classroom-friendly and readable from a projector.

```
