# SLIDE DECK - WEEK 2 DAY 1

* Course: 10-152-117 Python Programming
* Week / Day: Week 2 / Monday
* Date: August 24, 2026
* Weekly Theme: Decision Logic and Repetition
* Lecture Title: How Programs Make Decisions
* Assignments Supported: A2 - Decisions in Code
* Readiness Target: students can predict which branch runs and explain why
* Primary Watch Point: keep examples small; do not yet mix in too much loop complexity

---

### SLIDE 1 - OPENING FRAME

Programs can choose.
Not just run.

---
Cue:
- Frame this as the first move away from static scripts.
- Keep the emotional tone simple: the program now has more than one possible path.

Visual:
- Layout: Split contrast
- Content:
  - left: one straight path
  - right: path that branches in two directions
- Purpose:
  - show the conceptual jump from single-path output to conditional behavior

### SLIDE 2 - COURSE POSITIONING

Last week: output.
This week: logic.

---
Cue:
- Connect Week 2 directly to Week 1.
- Emphasize that logic builds on values and variables students already know.

Visual:
- Layout: Flow
- Content:
  - values
  - arrow to comparisons
  - arrow to branching
- Purpose:
  - show that decision logic is built from familiar pieces

### SLIDE 3 - CORE IDEA

Conditions ask a question.

---
Cue:
- Keep this very plain.
- Translate code into a yes/no question students can say out loud.

Visual:
- Layout: Isolated focus
- Content:
  - one comparison example
  - one large `True / False` outcome
- Purpose:
  - install the mental model that a condition is a question with a boolean result

### SLIDE 4 - CORE IDEA

One branch runs.
Not all of them.

---
Cue:
- Preempt the common beginner error that every block “somehow happens.”
- Ask students to predict the active branch before execution.

Visual:
- Layout: Split
- Content:
  - `if` path highlighted
  - alternate path dimmed
- Purpose:
  - make mutual exclusivity visible
