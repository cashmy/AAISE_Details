# AI Use

Use the course prompting pattern when AI is allowed:

```text
Context -> Attempt -> Allowed Help -> Constraints -> Questions -> Output
```

In your AI notes or disclosure, identify the closest AI use classification:

- **AI Assistance**: AI supported critique, explanation, review, or thinking.
- **AI Enabled / Collaboration**: AI helped create, revise, compare, or complete a targeted part after your manual framing.
- **AI Embedded**: AI was used inside a tool or system that directly supported the workflow.

Start manually.

State the system question and expected result before using AI or checking the final operation.

Allowed AI uses:

- ask AI to critique a query plan
- ask AI to suggest a MongoDB operation for your stated system question
- ask AI to explain operators in a suggested operation
- ask AI to help troubleshoot an empty or wrong result
- ask AI to identify whether the operation reveals a model issue

Not allowed:

- asking AI to create disconnected commands without a system question
- asking AI to change the document model before the operation is tested
- comparing MongoDB operations to SQL syntax
- submitting AI-generated operations without explaining the result

# Instructor Notes

This assignment should use operations as model evidence, not as isolated command practice.

The key teaching target is:

```text
document shape -> system question -> expected result -> operation evidence -> result explanation -> model insight
```

Do not let students jump to:

- disconnected command lists
- SQL comparisons
- advanced query coverage
- model changes that are not supported by operation evidence

Useful feedback patterns:

- Good: system question is clear, expected result is stated first, operation result is explained, model insight is connected to document shape.
- Improvements: operation has no system purpose, expected result is missing, result evidence is unclear, explanation only describes the command.
- Suggestions: write the question before the command, identify one field the result should show, explain what an empty result would mean, connect one result to a modeling decision.
