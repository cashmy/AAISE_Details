# Context

Aggregation and performance awareness can help you defend a modeling decision.

In this assignment, you will connect an aggregation or guided aggregation exercise to a system question, identify one performance consideration, and select evidence for your Week 8 modeling defense.

This assignment is not a deep aggregation programming assignment. The goal is to show how an operation supports a claim about your model.

SQL is not part of this assignment.

# AI Use

Use the course prompting pattern when AI is allowed:

```text
Context -> Attempt -> Allowed Help -> Constraints -> Questions -> Output
```

In your AI notes or disclosure, identify the closest AI use classification:

- **AI Assistance**: AI supported critique, explanation, review, or thinking.
- **AI Enabled / Collaboration**: AI helped create, revise, compare, or complete a targeted part after your manual framing.
- **AI Embedded**: AI was used inside a tool or system that directly supported the workflow.

Start manually.

State the system question, expected result, and performance note before using AI to critique the work.

Allowed AI uses:

- ask AI to critique whether aggregation evidence supports the system question
- ask AI to explain an aggregation stage
- ask AI to question whether a performance note is specific enough
- ask AI to critique a draft modeling claim
- ask AI to suggest evidence to bring into the final defense

Not allowed:

- asking AI to write the final defense for you
- asking AI to create disconnected aggregation examples
- comparing MongoDB operations to SQL syntax
- submitting AI output without explaining your decision

If you use AI, complete:

```text
ai_assistance_notes.md
```

Your notes should explain:

- the AI use classification
- what you completed manually first
- the context, attempt, allowed help, constraints, questions, and output format in your prompt
- the exact prompt you used
- what AI suggested or produced
- what you accepted, rejected, or changed
- what you verified yourself
- why the final decision remained yours

# Instructor Notes

This assignment should prepare students to defend a model using selected evidence, not overwhelm them with advanced aggregation.

The key teaching target is:

```text
system question -> aggregation evidence -> performance note -> evidence selection -> draft claim -> limitation
```

Do not let students jump to:

- advanced aggregation requirements
- disconnected pipeline examples
- SQL comparisons
- final defense polish before evidence is selected

Useful feedback patterns:

- Good: aggregation supports a real system question, performance note is specific, selected evidence supports the draft claim, limitation is honest.
- Improvements: aggregation is disconnected from the claim, performance note is generic, evidence selection includes everything, limitation is missing.
- Suggestions: choose the three strongest evidence items, explain one aggregation step in plain language, name one performance concern, soften an overclaim.
