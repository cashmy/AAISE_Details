# Document Boundary Worksheet Template

Course: `10-152-123 Modern Data Modeling for Systems`

---

# Purpose

Use this template when students need to move from a relational/table-shaped model to a first MongoDB document boundary.

The worksheet should foreground access patterns, embedding/reference choices, and tradeoffs.

Students should not compare SQL syntax to MongoDB syntax.
