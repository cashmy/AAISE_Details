# Purpose

Use this template when students need to revise a prior model and explain the reason for the change.

This template supports:

- evidence-based model revision
- conceptual pattern consideration
- scope and boundary control
- change log documentation
- quality self-assessment

Students should not write SQL as part of this revision log.
