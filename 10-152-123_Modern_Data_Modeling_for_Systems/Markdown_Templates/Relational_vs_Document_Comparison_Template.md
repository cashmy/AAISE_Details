Course: `10-152-123 Modern Data Modeling for Systems`

# Purpose

Use this template when students need to compare relational/table-shaped and document-shaped representations.

The comparison should focus on representation, retrieval, update responsibility, and tradeoffs.

Students should not compare SQL syntax to MongoDB syntax.
