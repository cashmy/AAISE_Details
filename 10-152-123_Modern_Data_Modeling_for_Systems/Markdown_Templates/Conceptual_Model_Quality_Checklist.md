# Conceptual Model Quality Checklist

Course: `10-152-123 Modern Data Modeling for Systems`

Use this checklist to review an early conceptual model.

The goal is not perfection. The goal is to improve the model enough to make the next modeling step possible.

---

# Quality Lenses

| Lens | Review Question | Notes |
| --- | --- | --- |
| Intent | Does the model clearly connect to what the system is supposed to support? |  |
| Audience | Is it clear who needs or uses this information? |  |
| Entity Purpose | Does each entity have a reason to exist? |  |
| Relationship Clarity | Are relationships stated clearly in plain English? |  |
| Missing Concepts | Is an important thing, event, category, or rule missing? |  |
| Ambiguity | Are any entities or relationships unclear or overloaded? |  |
| Scope Control | Is the model staying at the right level for the current assignment? |  |
| Next Step Readiness | Could this model be sharpened into relational structure next week? |  |

---

# Review Labels

Use these labels when reviewing feedback or AI suggestions:

| Label | Meaning |
| --- | --- |
| Accept | The suggestion fits the scenario and current scope. |
| Modify | The suggestion is useful but needs adjustment. |
| Reject | The suggestion does not fit the scenario or scope. |
| Verify Later | The suggestion might matter, but more information is needed. |
| Out of Scope | The suggestion may be real but is too advanced or detailed for this step. |
