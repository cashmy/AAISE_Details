# ERD Diagramming Worksheet Template

Course: `10-152-123 Modern Data Modeling for Systems`

---

# Purpose

Use this template when students need to turn a relational structure into a visible ERD.

This template supports:

- ERD planning before tool work
- draw.io or approved alternative tool use
- notation and readability review
- assumptions and design rationale

Students should not write SQL as part of this worksheet.

---

# Template Sections

1. Starting point from prior model
2. ERD planning table
3. Cardinality and relationship decisions
4. Diagram layout plan
5. AI critique prompt input block
6. Final ERD file information
7. Assumptions shown or explained
8. Design rationale
9. Final check
