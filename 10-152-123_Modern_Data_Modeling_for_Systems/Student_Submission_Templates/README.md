# Student Submission Templates

Course: `10-152-123 Modern Data Modeling for Systems`

---

# Purpose

This folder contains clean, student-facing submission templates.

Students can copy the appropriate weekly assignment folder into their own course repository and complete the files in place.

These templates are separate from instructor demos and worked examples.

---

# Recommended Student Repo Structure

Each student should organize course work by week and assignment:

```text
week_01/
  A1_conceptual_model_start_and_quality_revision/
    README.md
    conceptual_model_worksheet.md
    ai_assistance_notes.md
    optional_conceptual_sketch.md
```

Future weeks should follow the same pattern:

```text
week_<n>/
  A<assignment_number>_<assignment_name>/
    README.md
    evidence files...
```

---

# Submission Expectations

Unless your instructor gives different directions:

1. Do not delete template headings.
2. Complete each required section in place.
3. Keep evidence files inside the assignment folder.
4. Use `README.md` for assignment reflection and instructor feedback.
5. Commit the completed assignment folder to your course repository, or submit the files through the LMS if directed.

---

# Audit Purpose

This folder structure preserves visible assignment evidence for review.

Commit history is useful, but assignment folders provide a stable snapshot of:

- the work students submitted
- the reflection attached to that work
- instructor feedback
- artifacts used for grading
