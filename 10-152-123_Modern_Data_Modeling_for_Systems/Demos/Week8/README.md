# Week 8 Demo Package

Course: `10-152-123 Modern Data Modeling for Systems`

Week 8 is the capstone modeling defense. It is not a new numbered assignment. Students finalize, organize, and defend a database design using one approved pathway.

---

# Capstone Pathways

1. Continue and finalize the database concept used during Weeks 1-7.
2. Choose a remaining unused option from `Database_Concept_Options_v1.md` and complete a compressed conceptual design.
3. Design a database layer for a `10-152-117 Python Programming` or `10-152-118 Web Development Foundations` project.
4. Use a new instructor-approved concept.

Option 2 may rely heavily on AI assistance because the design is compressed. That pathway requires a stronger AI assistance disclosure.
