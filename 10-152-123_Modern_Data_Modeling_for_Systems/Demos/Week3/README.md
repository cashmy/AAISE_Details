# Tool Boundary

Supported classroom tool:

```text
draw.io / diagrams.net
```

Approved alternatives may include:

```text
Lucidchart
Miro
FigJam
ERDPlus
Visual Paradigm
Creately
Mermaid
```

Some tools can generate SQL or database scripts. Do not use those features in Course 123.
