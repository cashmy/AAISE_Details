# Purpose

Week 8 is reserved for final synthesis and the two-part final assessment.

This activity replaces the former full Week 8 lab. It gives students one final
guided example of how to compare approaches, explain evidence, identify
limitations, and account for AI use before they complete the final.

The goal is preparation, not a new major assignment.

# Instructor Demo Plan

## Demo Problem

Compare two approaches for assigning support tickets:

- first available technician
- priority-based assignment using ticket urgency and technician skill match

## What Students Should Notice

- different approaches can optimize for different goals
- working code is valuable but does not automatically mean the approach is best
- evidence should support the recommendation
- fairness, assumptions, and missing data matter
- the best explanation is clear to a stakeholder, not only to a programmer
- AI-generated suggestions still need validation and explanation

## Demo Evidence

Use a compact comparison table.

| Criterion | First Available | Priority + Skill Match | Evidence |
| --- | --- | --- | --- |
| Correctness |  |  |  |
| Efficiency |  |  |  |
| Readability |  |  |  |
| Assumptions |  |  |  |
| Risk or limitation |  |  |  |

## Transfer Bridge

> In the demo, we compare support-ticket assignment approaches. In the final,
> you will solve bounded algorithmic tasks, submit evidence, and explain your
> own decisions.

## Stop Point

Stop before turning the demo into a complete final-style submission. Students
should see the reasoning pattern without receiving an answer template that
solves the final for them.

# Student Practice

Students complete a short, low-stakes practice response based on the demo.

Possible prompts:

1. Which approach is easier to explain, and why?
2. Which approach may be more fair or useful, and what assumption does it make?
3. What evidence would you want before recommending one approach?
4. What edge case could make the chosen approach fail?
5. If AI suggested a third approach, what would you verify before trusting it?

The instructor may collect these responses as participation or use them as
informal readiness checks.

---

# Final Assessment Bridge

This activity prepares students for:

- **Final Part 1:** creating working algorithmic solutions with evidence
- **Final Part 2:** explaining submitted work, assumptions, tradeoffs, and AI use

Students should leave this session knowing that the final rewards:

- working solutions
- reasonable evidence
- clear explanation
- honest limitations
- accountable AI use

# Instructor Notes

- Keep the demo compact.
- Do not introduce a new algorithm family in Week 8.
- Reuse concepts from Labs 1-7.
- Emphasize that imperfect but working code can still be meaningful evidence.
- Emphasize that the explanation defense is not a gotcha.
- Make the final logistics clear before students begin Part 1.
