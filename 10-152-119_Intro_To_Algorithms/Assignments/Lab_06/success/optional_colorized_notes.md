# LAB 06 OPTIONAL COLORIZED NOTES - GRAPH TRAVERSAL AND MODELING

This optional file is a readability refinement for the Lab 06 successful
version. It preserves the same graph, traversal logic, and evidence as the
plain successful version.

---

# Purpose

The colorized version helps the reader inspect:

- section boundaries
- BFS output versus DFS output
- traversal comparison summaries
- the model-limit statement

The color changes presentation only. It does not change the modeled workflow,
the adjacency list, the traversal methods, or the evidence content.

---

# Implementation Notes

- ANSI color is used as the presentation layer.
- `NO_COLOR` disables color output.
- The primary successful version remains the plain required reference.
- This optional version is not a grading requirement.

---

# Relationship to the Plain Success Version

`optional_colorized_success_solution.py` preserves the same logic and output
content as `success_solution.py` while making BFS, DFS, and summary sections
easier to scan in a terminal that supports ANSI color.
