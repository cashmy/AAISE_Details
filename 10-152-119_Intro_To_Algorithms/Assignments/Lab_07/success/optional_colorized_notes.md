# LAB 07 OPTIONAL COLORIZED NOTES - SIMILARITY, RANKING, AND HASHING

This optional file is a readability refinement for the Lab 07 successful
version. It preserves the same hashing logic and evidence as the plain success
version.

---

# Purpose

The colorized version helps the reader inspect:

- section boundaries
- hash match versus mismatch status
- the assumption and limitation summary
- the AI/data connection note

The color changes presentation only. It does not change the dataset, hashing
logic, or evidence content.

---

# Implementation Notes

- ANSI color is used as the presentation layer.
- `NO_COLOR` disables color output.
- match rows are highlighted differently from mismatch rows.
- the primary successful version remains the plain required reference.
- this optional version is not a grading requirement.

---

# Relationship to the Plain Success Version

`optional_colorized_success_solution.py` imports the comparison rows from
`success_solution.py` so the algorithmic logic and evidence stay aligned.
