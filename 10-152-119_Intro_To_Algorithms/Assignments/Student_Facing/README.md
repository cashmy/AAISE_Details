# Student-Facing Assignments

This folder contains the student-facing assignment versions for
`10-152-119 Algorithmic Problem Solving`.

The files in this folder are intended for posting in Schoology or distributing
directly to students.

They are separated from the instructor/Codex source artifacts in the parent
`Assignments/` folder so that student instructions stay clean and do not include
instructor demo plans, prompt-generation notes, stop points, or successful
version guidance.

Each student-facing assignment includes:

- context
- objective
- task
- requirements
- AI use boundary
- submission requirements
- reflection / explanation
- rubric grading emphasis
- success criteria

Several labs also have full-English walkthrough artifacts. These are optional
support documents that can be posted, hidden, or assigned selectively when
students need additional scaffolding. They are not answer keys; they model how
to reason through the task before writing code.

Rubric emphasis is based on:

- `../v2/MRS-AL_Master_Rubric_System.md`

The parent assignment files remain useful as instructor planning and Codex code
generation sources.
