# LAB 3 - DATA STRUCTURE CHOICE

**Week 3 - Data Structures for Algorithmic Thinking**

---

# Context

Data structures shape what is easy, expensive, clear, or awkward.

In this lab, you will solve the same small problem using two different
representations and explain which one better fits the task.

---

# Objective

Compare two data structure choices for the same problem.

Your work should demonstrate:

- meaningful use of two structures
- explanation of access patterns
- correct Python implementation or simulation
- comparison of clarity and tradeoffs

---

# Task

Choose or use an instructor-assigned scenario:

- inventory lookup
- student score summary
- help desk ticket status
- menu item search
- simple contact lookup
- event registration list

Solve the problem using two different structures.

Possible pairings:

- list vs dictionary
- list vs set
- stack vs queue
- list of dictionaries vs dictionary of dictionaries

---

# Requirements

Your submission must include:

1. A short problem statement.
2. A description of the two structures you selected.
3. A Python implementation or simulation using each structure.
4. At least `3` operations to compare, such as add, lookup, update, remove, or
   display.
5. A comparison table explaining which structure fits each operation better.
6. A short recommendation naming the better overall fit for the scenario.

---

# Evidence Requirements

Include a comparison table.

Example structure:

| Operation | Structure A | Structure B | Better Fit | Why? |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

You may also include a small diagram of how the data is stored.

---

# AI Use

Start manually.

You may use AI after you have selected your two structures and written an
initial comparison.

Allowed AI uses:

- ask AI for an alternate representation
- ask AI to critique your structure choice
- ask AI to explain a tradeoff

You remain responsible for the final recommendation.

---

# Submission Requirements

Submit your files or written response as instructed.

Your submission should include:

- problem statement
- two structures
- implementation or simulation
- operation comparison
- comparison table
- recommendation
- AI-use note, if applicable

---

# Reflection / Explanation

Answer briefly:

> Which data structure better fit your problem, and what access pattern made it
> a better fit?

If you used AI:

> Did AI suggest a structure you did not choose? Why did you accept or reject it?
