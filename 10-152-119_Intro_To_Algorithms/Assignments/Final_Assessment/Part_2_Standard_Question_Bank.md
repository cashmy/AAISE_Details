# PART 2 STANDARD QUESTION BANK

**10-152-119 Algorithmic Problem Solving**

---

# Purpose

This instructor-facing artifact provides standardized Part 2 explanation
questions for the final assessment.

These questions may be used as-is or adapted after reviewing a student's Part 1
submission.

The goal is to verify understanding, not to trap the student.

---

# Recommended Use

Select `5-8` questions.

For a fully standardized Part 2, use the core question set below.

For a partially personalized Part 2, keep the same categories but refer to
specific functions, tests, tables, or decisions from the student's submission.

---

# Core Standardized Questions

## 1. Overall Walkthrough

Explain one of your submitted tasks from input to output.

What this verifies:

- whether the student understands the main flow of their own solution
- whether they can connect code to problem intent

Minimally acceptable answer:

- names the input
- names the output
- describes the main steps in order

Stronger answer:

- references assumptions, test evidence, and why the step order matters

---

## 2. Task 1 Decision Logic

In Task 1, what rule or condition has the highest priority in your decision
algorithm, and why?

What this verifies:

- rule ordering
- decision precision
- awareness of hidden assumptions

Minimally acceptable answer:

- identifies one important rule
- explains why it should be checked early

Stronger answer:

- explains a conflict between rules or an edge case affected by rule order

---

## 3. Task 1 Edge Case

Choose one edge case from Task 1. What did it test, and what did you learn from
it?

What this verifies:

- correctness evidence
- boundary or missing-information reasoning

Minimally acceptable answer:

- identifies the edge case and expected result

Stronger answer:

- explains how the edge case exposed ambiguity or confirmed a rule

---

## 4. Task 2 Approach Comparison

In Task 2, how are the two duplicate-detection approaches different?

What this verifies:

- strategy comparison
- data structure awareness
- basic efficiency reasoning

Minimally acceptable answer:

- describes both approaches
- identifies which one uses a supporting structure

Stronger answer:

- connects repeated work, readability, input size, or Big-O intuition to the
  comparison

---

## 5. Task 2 Evidence

What evidence shows that your two Task 2 approaches produced the same result?

What this verifies:

- test/evidence interpretation
- connection between output and correctness

Minimally acceptable answer:

- points to a test set or table row showing matching outputs

Stronger answer:

- explains why matching output is necessary but not the only thing to consider

---

## 6. Task 3 Representation

In Task 3, what do the tags or features represent, and what do they leave out?

What this verifies:

- representation awareness
- AI/data model limitation awareness

Minimally acceptable answer:

- explains that tags/features represent simplified request and resource
  information
- names one thing the model leaves out

Stronger answer:

- explains how missing or weighted features could change the ranking

---

## 7. Task 3 Recommendation

Why did your top-ranked resource become the recommendation?

What this verifies:

- ranking logic
- score interpretation
- evidence-based recommendation

Minimally acceptable answer:

- references the score or shared-tag evidence

Stronger answer:

- explains why the result is useful but not absolute

---

## 8. AI/Tool Accountability

If you used AI or other tools, what did they help with, and how did you verify
the output?

If you did not use AI, describe one place where AI could have been helpful and
what you would have needed to verify.

What this verifies:

- responsible tool use
- ownership of submitted work

Minimally acceptable answer:

- identifies tool use or a possible tool-use point
- gives one validation step

Stronger answer:

- distinguishes accepted, changed, rejected, and personally verified output

---

## 9. Improvement With More Time

If you had one more hour to improve your final submission, what would you
change first?

What this verifies:

- reflection
- practical prioritization
- awareness of limitations

Minimally acceptable answer:

- identifies one specific improvement

Stronger answer:

- explains why that improvement would most improve correctness, evidence,
  readability, efficiency, or user value

---

# Optional Previous-Work Reference Question

If you used your own previous lab work, notes, code, or examples as a reference,
what did you reuse or adapt, and how did you make sure it fit the final task?

What this verifies:

- transfer of learning
- adaptation rather than copying without understanding
- ability to explain code lineage and design choices

Minimally acceptable answer:

- identifies the previous work referenced
- names one change made for the final

Stronger answer:

- explains why the earlier work was relevant, what had to change, and how the
  adapted version was tested or verified

---

# Optional Personalized Question Stems

Use these when a student's submission needs targeted follow-up.

- In your function named `____`, what happens when `____`?
- Your evidence table shows `____`. What does that prove?
- Your solution uses a `____`. Why does that structure fit the task?
- What would happen if the input contained `____`?
- Where does your solution repeat work?
- What part of your solution would be hardest to debug?
- What assumption would be risky in a real system?
- If AI suggested this code, what part would you check first?

---

# Scoring Reminder

Part 2 should verify understanding of submitted work.

It should not require obscure recall unrelated to the student's solution.
