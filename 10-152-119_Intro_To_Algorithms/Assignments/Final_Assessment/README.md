# FINAL ASSESSMENT PACKAGE

**10-152-119 Algorithmic Problem Solving**

---

# Purpose

This folder contains the working final-assessment materials for the two-part
final.

The existing final assessment and WIDS rubric artifacts remain the reference
governance documents. This folder provides the concrete student-facing task set,
starter files, README template, and standardized Part 2 question bank.

# Assessment Shape

Part 1 includes three applied tasks:

1. Equipment checkout eligibility
2. Duplicate registration detection
3. Support resource recommendation

Part 2 asks students to explain their submitted work.

The question bank supports either standardized or personalized Part 2 delivery.

---

# Instructor Note

The starter files intentionally do not solve the tasks.

They provide structure, docstrings, TODOs, small example shapes, and guidance so
students can focus on algorithmic reasoning, evidence, and explanation instead
of blank-page setup.

The `success/` files are withheld examples. They should normally be released
only after the final has been completed and graded. They show one acceptable
solution path for each task, not the only correct solution.
