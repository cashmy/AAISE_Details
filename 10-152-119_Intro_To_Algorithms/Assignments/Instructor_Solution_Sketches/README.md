# Instructor Solution Sketches

This folder contains instructor-only solution calibration notes for
`10-152-119 Algorithmic Problem Solving`.

These sketches are not student walkthroughs and are not full runnable solution
packages. They exist to help the instructor quickly evaluate, discuss, or expand
the multiple option paths allowed in the student-facing labs.

---

# Purpose

The student-facing labs intentionally allow multiple scenarios and option
choices. The runnable success folders usually implement one acceptable version.
That is useful for validation, but it can under-prepare the instructor when
students choose other valid options.

These sketches fill that gap by capturing the instructor judgment layer:

- viable scenario framing
- recommended representation or strategy
- expected evidence
- likely edge cases
- grading watch-fors
- notes for turning the sketch into runnable code later

---

# Relationship To Other Artifacts

| Artifact Type | Audience | Purpose |
| --- | --- | --- |
| Student-facing lab | Students | Defines required work and grading emphasis |
| Full-English walkthrough | Students, optionally assigned | Provides reasoning scaffolding without becoming an answer key |
| Runnable success package | Instructor / possible post-grade release | Shows one complete working version |
| Instructor solution sketch | Instructor only | Calibrates grading and prepares alternate option support |

---

# Use Guidance

Use these sketches when:

- a student chooses an option different from the runnable success version
- you need to answer a question during lab time
- you want to create a quick alternate demo
- you want to calibrate grading across different student choices
- you want to generate a full solution package later

Do not post these files directly to students.

If a sketch is converted into a student-facing example, rewrite it first so it
does not expose grading shortcuts or expected answers.
