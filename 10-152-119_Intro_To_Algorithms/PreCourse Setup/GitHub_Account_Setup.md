# **GitHub Account Setup**

---

## **Purpose**

This guide walks you through creating your GitHub account for this course.

Please use your `swtc.edu` email address when creating your account.

---

## **Why You Need a GitHub Account**

In this course, GitHub may be used to help you:

* store code
* track changes over time
* submit or share programming work when needed
* preserve your work across labs and final assessment preparation

You do not need to be an expert in Git or GitHub before class starts.

You only need to create your account correctly and be able to sign in.

---

## **Instructions**

### **1. Go to GitHub**

Open:

* [https://github.com](https://github.com)

Click **Sign up**.

---

### **2. Use Your SWTC Email**

When GitHub asks for your email address, use your:

* `yourname@swtc.edu`

Use your school email for this course account setup unless your instructor tells
you otherwise.

---

### **3. Create a Username**

Choose a username that is:

* school-appropriate
* professional
* something you will be comfortable using in a course setting

Try to avoid usernames that are difficult to recognize, joke-based, or overly
random.

---

### **4. Create a Password**

Choose a strong password that you can store safely.

If you use a password manager, this is a good place to use it.

---

### **5. Verify Your Account**

GitHub may ask you to:

* solve a verification step
* confirm your email address

Check your `swtc.edu` email inbox and complete the verification if prompted.

---

### **6. Sign In**

After your account is created and verified, sign in to make sure everything
works.
