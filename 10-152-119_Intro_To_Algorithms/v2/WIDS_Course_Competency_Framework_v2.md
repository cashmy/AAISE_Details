## Description

Learners develop algorithmic problem-solving skills by analyzing problems,
selecting data structures and solution strategies, implementing algorithms in
Python, and evaluating correctness, efficiency, readability, and tradeoffs. The
course introduces Big-O reasoning, core data structures, searching, sorting,
recursion, graph thinking, and selected algorithmic foundations for AI, data
analytics, and data modeling. Students use visual or tangible lab evidence to
observe algorithm behavior and learn to compare manual, library-supported, and
AI-assisted approaches responsibly.

## Course Competencies

### 1. Analyze problems to define algorithmic solutions

Assessment Strategies:

- Project assignments
- Lab activities
- Quizzes

Criteria:

Learners will be successful when they are able to:

- Decompose problems into clear steps.
- Identify inputs, outputs, constraints, assumptions, and edge cases.
- Distinguish between clear and ambiguous problem statements.
- Represent solution logic using pseudocode, diagrams, traces, or code.
- Explain why a proposed approach fits the problem.

Learning Objectives:

- Define an algorithm and its key characteristics.
- Explain problem decomposition and abstraction.
- Identify problem constraints and assumptions.
- Describe algorithmic solutions before implementation.

### 2. Select and use data structures to support algorithmic solutions

Assessment Strategies:

- Project assignments
- Lab activities
- Quizzes

Criteria:

Learners will be successful when they are able to:

- Use lists, dictionaries, sets, stacks, queues, trees, and graphs at an
  introductory level.
- Match data structures to access, lookup, ordering, traversal, or membership
  needs.
- Explain how a data structure affects solution clarity and performance.
- Represent simple relationships or workflows using appropriate structures.

Learning Objectives:

- Identify common data structures used in algorithmic solutions.
- Explain basic tradeoffs among common data structures.
- Describe how representation affects algorithm design.
- Use Python structures to support algorithm implementation.

### 3. Implement and test introductory algorithms using Python

Assessment Strategies:

- Project assignments
- Lab activities
- Quizzes

Criteria:

Learners will be successful when they are able to:

- Implement introductory searching, sorting, recursive/iterative, and graph
  traversal algorithms.
- Translate algorithmic logic into readable Python code.
- Test solutions using normal cases, edge cases, and expected outcomes.
- Identify and correct logical errors.
- Use libraries appropriately when implementation is not the learning target.

Learning Objectives:

- Describe how core programming constructs support algorithms.
- Implement algorithmic steps in Python.
- Explain the relationship between pseudocode and executable code.
- Apply testing to verify algorithm correctness.

### 4. Evaluate correctness, efficiency, and tradeoffs

Assessment Strategies:

- Project assignments
- Lab activities
- Quizzes

Criteria:

Learners will be successful when they are able to:

- Verify whether an algorithm produces expected results.
- Compare multiple solutions to the same problem.
- Apply introductory Big-O reasoning to describe growth behavior.
- Discuss tradeoffs among correctness, simplicity, readability, efficiency, and
  maintainability.
- Use timing data, traces, diagrams, or other evidence to support evaluation.

Learning Objectives:

- Define correctness in an algorithmic context.
- Explain common growth patterns such as constant, linear, quadratic, and
  logarithmic behavior.
- Identify common sources of inefficiency or incorrect assumptions.
- Describe tradeoffs in algorithm selection.

### 5. Connect algorithmic thinking to AI, analytics, data modeling, and responsible tool use

Assessment Strategies:

- Project assignments
- Lab activities
- Quizzes
- Reflection or explanation artifacts

Criteria:

Learners will be successful when they are able to:

- Recognize how similarity, clustering, recommendation, hashing, and
  representation support AI and data systems.
- Explain how assumptions, bias, incomplete data, or poor representation can
  affect algorithmic outcomes.
- Compare manual, library-supported, and AI-assisted solutions when appropriate.
- Identify limitations, inaccuracies, or hidden assumptions in AI-generated
  algorithmic output.
- Communicate algorithmic choices clearly to technical and non-technical
  audiences.

Learning Objectives:

- Describe selected algorithmic foundations of AI and data systems.
- Explain why algorithms require validation and interpretation.
- Identify responsible uses and limits of AI-assisted development.
- Communicate solution choices and tradeoffs clearly.

## Assessment Methods

- Weekly lab-based algorithm assignments
- Short quizzes for concept reinforcement
- Visual or tangible demonstrations of algorithm behavior
- Comparative analysis of solution approaches
- Final applied comparison or explanation task

## Course Alignment Notes

This course refines the problem-solving habits established in
`10-152-117 Python Programming` and prepares students for database, advanced
Python, data modeling, analytics, and AI coursework. The course uses Python as
the primary implementation language while emphasizing algorithmic reasoning over
syntax coverage.
