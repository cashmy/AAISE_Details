# Course Competency Framework

## Course Information

**Course Title:** Introduction to Algorithms  
**Course Number:** 10-152-119  
**Credits:** 3  
**Lecture Hours:** 36  
**Lab Hours:** 36  
**Total Hours:** 72  
**Prerequisite:** 10-152-117 Python Programming  
**Instructional Level:** 10  

---

## Description

Learners develop algorithmic problem-solving skills by analyzing problems, selecting data structures and solution strategies, implementing algorithms in Python, and evaluating correctness, efficiency, readability, and tradeoffs. The course introduces Big-O reasoning, core data structures, searching, sorting, recursion, graph thinking, and selected algorithmic foundations for AI, data analytics, and data modeling. Students use visual or tangible lab evidence to observe algorithm behavior and learn to compare manual, library-supported, and AI-assisted approaches responsibly.

---

## Framework Design Note

This version expands the WIDS Course Competency Framework into a detailed source artifact with a direct one-to-one relationship to the Algorithmic Problem Solving Master Rubric System (MRS-AL). The first six competencies align to the course-specific technical rubric categories (T1-T6). The final six competencies align to the cross-course core ability rubric categories (C1-C6), refracted through observable algorithmic work.

This structure preserves the institutional usefulness of WIDS competencies while making the competency-to-rubric relationship easy to recognize for non-technical reviewers.

# Course Competencies

## 1. Frame problems and analyze algorithmic requirements

**MRS Mapping:** T1. Problem Framing and Algorithmic Analysis  
**Domain:** Cognitive  
**Level:** Analyzing  
**Status:** WIP  

### Assessment Strategies

* Problem-framing activities
* Lab-based algorithm assignments
* Pseudocode, diagram, trace, or explanation artifacts
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Decompose problems into clear algorithmic steps
* Identify inputs, outputs, constraints, assumptions, and edge cases
* Distinguish between clear and ambiguous problem statements
* Represent solution logic using pseudocode, diagrams, traces, or code
* Explain why a proposed approach fits the problem

### Learning Objectives

* Define an algorithm and its key characteristics
* Explain problem decomposition and abstraction
* Identify problem constraints, assumptions, and edge cases
* Describe algorithmic solutions before implementation

## 2. Select data structures and representations for algorithmic solutions

**MRS Mapping:** T2. Data Structures and Representation  
**Domain:** Cognitive  
**Level:** Analyzing  
**Status:** WIP  

### Assessment Strategies

* Data-structure selection activities
* Representation comparison tasks
* Lab-based algorithm assignments
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Use lists, dictionaries, sets, stacks, queues, trees, and graphs at an introductory level
* Match data structures to access, lookup, ordering, traversal, or membership needs
* Explain how representation affects solution clarity and performance
* Represent simple relationships, workflows, or traversals using appropriate structures
* Justify representation choices using task requirements and constraints

### Learning Objectives

* Identify common data structures used in algorithmic solutions
* Explain basic tradeoffs among common data structures
* Describe how representation affects algorithm design
* Use Python structures to support algorithm implementation

## 3. Implement and test introductory algorithms using Python

**MRS Mapping:** T3. Algorithm Implementation and Testing  
**Domain:** Cognitive  
**Level:** Applying  
**Status:** WIP  

### Assessment Strategies

* Python algorithm implementation labs
* Search, sort, recursion, and traversal activities
* Testing and expected-outcome checks
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Implement introductory searching, sorting, recursive, iterative, and graph traversal algorithms
* Translate algorithmic logic into readable Python code
* Test solutions using normal cases, edge cases, and expected outcomes
* Identify and correct logical errors
* Use libraries appropriately when implementation is not the learning target

### Learning Objectives

* Describe how core programming constructs support algorithms
* Implement algorithmic steps in Python
* Explain the relationship between pseudocode and executable code
* Apply testing to verify algorithm correctness

## 4. Evaluate correctness, efficiency, and tradeoffs among algorithmic approaches

**MRS Mapping:** T4. Correctness, Efficiency, and Tradeoff Evaluation  
**Domain:** Cognitive  
**Level:** Evaluating  
**Status:** WIP  

### Assessment Strategies

* Correctness and efficiency comparisons
* Big-O reasoning activities
* Timing or trace evidence tasks
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Verify whether an algorithm produces expected results
* Compare multiple solutions to the same problem
* Apply introductory Big-O reasoning to describe growth behavior
* Discuss tradeoffs among correctness, simplicity, readability, efficiency, and maintainability
* Use timing data, traces, diagrams, or other evidence to support evaluation

### Learning Objectives

* Define correctness in an algorithmic context
* Explain common growth patterns such as constant, linear, quadratic, and logarithmic behavior
* Identify common sources of inefficiency or incorrect assumptions
* Describe tradeoffs in algorithm selection

**MRS Mapping:** T5. Observable Algorithm Behavior and Communication Evidence

**Level:** Applying  
**Status:** WIP  

### Assessment Strategies

* Trace, table, chart, or diagram activities
* Visual or tangible algorithm demonstrations
* Comparative explanation tasks
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Use traces, tables, charts, diagrams, simulations, or other evidence to show algorithm behavior
* Connect evidence to claims about correctness, efficiency, or tradeoffs

## 6. Connect algorithmic thinking to AI, data systems, and responsible tool use

**MRS Mapping:** T6. AI/Data Foundations and Responsible Tool Use  
**Domain:** Cognitive  
**Level:** Evaluating  
**Status:** WIP  

### Assessment Strategies

* AI/data bridge activities
* Similarity, clustering, recommendation, hashing, or representation tasks
* AI/tool-use justification activities
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Recognize how similarity, clustering, recommendation, hashing, and representation support AI and data systems
* Explain how assumptions, bias, incomplete data, or poor representation can affect algorithmic outcomes
* Compare manual, library-supported, and AI-assisted solutions when appropriate
* Identify limitations, inaccuracies, or hidden assumptions in AI-generated algorithmic output
* Use AI or other tools transparently while validating output and explaining human decisions

### Learning Objectives

* Describe selected algorithmic foundations of AI and data systems
* Explain why algorithms require validation and interpretation
* Identify responsible uses and limits of AI-assisted development
* Communicate tool-assisted solution choices and tradeoffs clearly

**Domain:** Cognitive  
**Level:** Analyzing  
**Status:** WIP  

### Assessment Strategies

* Troubleshooting activities
* Strategy-selection tasks
* Lab-based algorithm assignments
* Project assignments or quiz

### Criteria

Learners will be successful when they are able to:

* Analyze problems before selecting a solution strategy

# Course Alignment Notes

This course refines the problem-solving habits established in `10-152-117 Python Programming` and prepares students for database, advanced Python, data modeling, analytics, and AI coursework. Python remains the primary implementation language, but the course emphasizes algorithmic judgment: framing problems, selecting representations, implementing and testing solutions, evaluating tradeoffs, using evidence, and explaining responsible tool-supported decisions.
