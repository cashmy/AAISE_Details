# 🧭 **WEEK 9 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 9 — Input, State, and User Interaction*

---

## **1. Re-Anchor the Week**

> “This week is about turning user input into meaningful behavior.”

---

## **2. Deep Concept Focus**

* Input becomes data
* Data affects application state
* State drives behavior
* Interaction becomes two-way

---

## **3. Common Confusion Patterns**

* “Why is my input empty?” → incorrect selection or timing
* “Why does the page refresh?” → form submission behavior
* “It works once but not again” → state issues

---

## **4. Thinking Tools / Heuristics**

* “What value am I capturing?”
* “When is this value available?”
* “What happens after input is received?”
* “Where is this value stored?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, improve clarity and reliability of your input handling.”

Examples:

* better labels
* clearer output
* consistent behavior

---

## **6. Closing Reinforcement**

> “User input is what makes applications useful.”
