## Proposed Reading Selections

### **Foundation and Core Concepts**
**Chapter 1: What Is a Database?**
- Understanding database fundamentals vs. spreadsheets/files
- Database types and basic concepts

**Chapter 2: The Relational Model and Types of Databases**
- Relational model components
- Key database types and their characteristics

### **Data Modeling and Design**
**Chapter 3: Designing Data: Modeling and ER Diagrams**
- Entity-relationship modeling
- Conceptual to logical design process
- Visualizing data relationships

**Chapter 4: Keys, Relationships, and Integrity**
- Primary and foreign keys
- Relationship types and constraints
- Data integrity principles

**Chapter 5: Normalization: Designing Tables That Behave**
- First through Third Normal Forms
- Normalization as design principle
- When to normalize vs. denormalize

### **SQL Query Fundamentals**
**Chapter 6: Speaking SQL - Getting Started with SQL**
- Basic SQL syntax and structure
- SQL environment setup

**Chapter 7: Retrieving Data with SELECT**
- SELECT statement fundamentals
- Column selection and basic queries

**Chapter 8: Filtering and Sorting Results**
- WHERE clause filtering
- ORDER BY sorting
- Basic comparison operators

**Chapter 9: Transforming Values with Functions**
- Built-in SQL functions
- Data type conversions
- String and numeric functions

### **Advanced Querying**
**Chapter 10: Combining Tables with JOINs**
- INNER JOIN fundamentals
- LEFT, RIGHT, and FULL joins
- Join strategies and performance considerations

**Chapter 11: Summarizing Data: Aggregation and Grouping**
- Aggregate functions (COUNT, SUM, AVG, etc.)
- GROUP BY and HAVING clauses
- Window functions introduction

**Chapter 12: Subqueries and Set Operations**
- Subquery types and usage
- EXISTS and IN operators
- Set operations (UNION, INTERSECT, etc.)

### **Data Manipulation and Structure**
**Chapter 13: Data Manipulation: INSERT, UPDATE, DELETE**
- CRUD operations fundamentals
- Safe data modification practices

**Chapter 14: Creating and Altering Tables**
- DDL statements
- Table structure modification
- Schema evolution considerations

**Chapter 15: Choosing Data Types**
- Appropriate data type selection
- Data type implications for storage and performance

**Chapter 16: Enforcing Rules with Constraints**
- NOT NULL, CHECK, DEFAULT constraints
- Naming and managing constraints
- Business rule enforcement at database level

### **Views, Indexes, and Performance**
**Chapter 17: Views and Indexes**
- Creating and using views
- Index fundamentals and tradeoffs
- Performance considerations

**Chapter 18: Making It Fast: Performance and Optimization Basics**
- Query optimization basics
- Index usage patterns
- Common performance mistakes

### **Transactions and Data Integrity**
**Chapter 19: Transactions and Data Consistency**
- ACID properties
- BEGIN, COMMIT, ROLLBACK
- Concurrency and isolation levels

### **Modern Context**
**Chapter 20: Beyond Relational: A Tour of Other Database Types**
- NoSQL introduction
- When to use relational vs. non-relational
- MongoDB overview (brief)

**Chapter 21: Database Systems Overview**
- SQLite, MySQL, PostgreSQL, SQL Server, Oracle
- Vendor-neutral SQL considerations
- Cloud database concepts

### **Security and Operations**
**Chapter 22: Security, Backup, and Recovery**
- Access control fundamentals
- SQL injection prevention
- Basic backup and recovery concepts

## Selection Rationale

**Emphasis Areas:**
- Relational fundamentals and normalization (core to course description)
- SQL query construction and manipulation (primary skill development)
- Data integrity and constraints (quality focus)
- Performance awareness (practical application)

**Modern Context Integration:**
- Brief NoSQL exposure to prepare for course 123
- Security awareness without deep implementation
- Cloud database awareness for future courses

**Potential Reduction Areas:**
- Advanced stored procedures/triggers (ORMs handle much of this)
- Deep physical implementation details (abstracted by modern tools)
- Extensive vendor-specific content (focus on vendor-neutral concepts)
