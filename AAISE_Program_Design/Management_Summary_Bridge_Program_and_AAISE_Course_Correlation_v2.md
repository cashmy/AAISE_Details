# Management Summary - Bridge Program and AAISE Course Correlation v2

## Purpose

This artifact provides a management-level summary of the currently identified
bridge-program direction and its emerging correlation to the future AAISE
program.

review. It is not a final catalog proposal.

Its purpose is to show:

- the semester-by-semester developmental intent
- the current `10-152-nnn` course structure
- the suggested bridge-program changes now under consideration
- the corresponding AAISE-facing nomenclature direction

## Gross Bridge Changes in This Pass

The current gross bridge changes under active consideration are:

- replace `10-152-123 SQL Programming Advanced` with
  **Modern Data Modeling for AI-Enabled Systems**
- rename `10-152-122 C# Programming` to
  **C# & ASP.NET Programming**
- drop `10-152-125 ASP.NET Programming` as a standalone course, merge its
  core exposure into the revised C# course, and repurpose the slot
- rename `10-152-128 C++ Programming` to
  **C++ Systems Performance and AI Runtime Foundations**
- use `10-152-127 AI-Driven Systems Analysis` as a primary carrier for
  **RBA-based systems framing**
- move `10-152-131 Machine Learning and AI` into **Semester 3**
- rename and repurpose `10-152-133 Enterprise Data Systems & API Architecture`
  as **Deep Learning Frameworks and Applications**
- retain `10-152-130 Software Career Experience` as the bridge nomenclature,
  while redirecting its underlying concept toward
  **Applied Software Integration Studio**

## New AAISE Additions and Injection Note

Two newly proposed AAISE-oriented courses remain relevant to the future program
structure:

- **Emerging Technology Intelligence for AI-Augmented Engineers**
- **Technical Intelligence Studio for AI-Augmented Engineers**

These appear strongest as explicit AAISE courses.

For the bridge program, one, the other, or both may need to be injected into
existing `10-152-nnn` courses so the concepts can be tested under current
governance constraints before a fuller AAISE rollout.

## Management-Level Read

This correlation suggests that the bridge does not need a total rebuild in
order to become meaningfully more AI-era aligned.

Instead, the strongest near-term direction appears to be:

- preserve the semester progression
- modernize course naming where governance latitude allows
- use broader, adaptation-friendly course identity for the future AAISE
- fold redundant legacy content together where appropriate
- create clearer space for RBA, AI-injected systems reasoning, and applied
  integration

This keeps the bridge practical while making the future AAISE structure more
legible.
