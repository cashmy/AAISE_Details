# White Paper Executive Summary v1

## Title

**From Legacy Software Curriculum to AI-Era Program Design**

## Subtitle

**A Bridge Model for Moving from Conventional Software Programs to AI-Era Workforce Preparation**

## The Challenge

Wisconsin technical college software-related programs were largely designed in
a pre-AI context. That does not mean those programs have lost their value, but
it does mean they were not originally built for a workforce in which software
development now occurs across multiple coexisting realities: conventional
development, AI-assisted development, AI-injected application development, and
AI-embedded systems operating on organizational data and workflow.

The current challenge, therefore, is not simply to add AI topics to an existing
software curriculum. The deeper challenge is to redesign software education so
that students can remain employable in conventional environments while also
developing the capability to work responsibly and effectively in AI-shaped
development contexts. If AI modernization is framed too narrowly as tool use,
prompting, or a single machine learning course, the resulting curriculum will
likely undershoot the actual shift taking place in software practice.

## The Bridge Approach

This white paper argues for a practical transition model rather than a purely
greenfield replacement approach. Under current statewide governance realities,
Southwest Tech is using the approved IT Software Developer program as a bridge
structure for AI-injected redesign. This bridge approach allows the college to
begin integrating AI-era capabilities now while also generating concrete design
evidence that can inform a future, more coherent Associates AI Software
Engineering (AAISE) successor program.

This transition logic is important because the redesign problem is not only
curricular. It is also operational. Current and future program models may
overlap for at least a year. Students may need to move between pathways. Faculty
need a realistic implementation path. Institutions need a model that is not
only conceptually stronger, but also administratively workable and clear enough
to support review, advising, and adoption.

## Why the Current Work Matters

Southwest Tech's current bridge work suggests that meaningful progress can begin
inside existing structures without waiting for full statewide redesign. Early
course-level work is already showing practical patterns that matter:

- foundational content can be preserved while AI is introduced in bounded and
  governed ways
- students can be taught to distinguish different roles for AI in their
  workflow
- data, APIs, architectural thinking, and justification of AI use can enter
  earlier than traditional software curricula often allow

These patterns are not yet full proof of final curriculum effectiveness, but
they do provide grounded direction for further development.

## Three Core Ideas

This paper proposes that statewide software-program modernization should be
guided by three ideas.

First, software curriculum must now account for multiple Workforce Models rather
than assume one stable development environment.

Second, a bridge-first strategy offers a practical path for modernizing current
programs without pretending the final AI-era program architecture is already
settled.

Third, future redesign should be governed by graduate capability targets rather
than by inherited "teach everything" coverage habits that overload curriculum
without necessarily improving integrative readiness.

## What This Adds

Under this model, the bridge pathway preserves strong software foundations while
expanding the curriculum to include:

- governed AI-assisted development
- AI role selection and justification
- modern data modeling
- AI-injected application design
- collaborative delivery workflow
- stronger systems and architectural thinking

At the same time, the bridge can reveal where the current program structure
still falls short and where a future Associates AI Software Engineering (AAISE)
successor program would benefit from cleaner sequencing, more coherent course
grouping, and a more explicit AI-era identity.

## Why It Matters Now

The opportunity before Wisconsin technical colleges is not merely to insert AI
into legacy curriculum. It is to design a more relevant and durable software
education model for a mixed workforce future.

Southwest Tech's current bridge effort may offer a practical pilot logic for
that work: preserve what still matters, modernize what no longer fits, and use
structured transition rather than abrupt replacement to move toward a stronger
statewide model.
