# Appendix B. Workforce Model Definitions

This appendix provides a concise reference for the four Workforce Models used in
the white paper.

These distinctions matter because the phrase "AI in software education" is too
broad on its own. Different workforce conditions require different kinds of
preparation.

---

## 1. Native

Conventional software development without official AI participation in either
the delivered product or the approved development workflow.

This remains a real workforce condition and still requires strong conventional
software capability.

---

## 2. AI-Assisted

Software work in which AI supports the human workflow but is not part of the
delivered system itself.

This includes uses such as:

- coding assistance
- debugging support
- documentation drafting
- summarization
- research and search support
- comparison of options

---

## 3. AI-Injected

Software work in which AI is intentionally introduced into the application or
solution architecture as part of the system's designed behavior or supported
workflow.

This is more than adding a superficial AI feature. It implies purposeful
integration in which the role, boundaries, and value of AI are architecturally
justified.

This can also include emerging agentic patterns in which AI participates in
multi-step operations, orchestrated tool use, or governed action flows within a
designed system context.

---

## 4. AI-Embedded

Software work in which AI becomes part of the internal operating logic of the
system or business workflow itself, especially in relation to organizational
data, analysis, prediction, transformation, decision support, or generative
operations.

Here AI is not peripheral. It participates directly in how the system functions
internally.

---

## Why These Definitions Matter

These Workforce Models help clarify why a modern software program cannot be
designed as if there were only one stable future condition.

Graduates may enter environments that range from fully conventional to strongly
AI-enabled. A useful software curriculum should therefore prepare students for
movement across these conditions rather than for only one narrow interpretation
of AI.
