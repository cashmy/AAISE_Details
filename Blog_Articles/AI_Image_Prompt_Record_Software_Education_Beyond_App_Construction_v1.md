# AI Image Prompt Record

## Purpose

This artifact records the image concept and prompt for the article:

- `Why Software Education Must Move Beyond App Construction`

It is intended for:

- LinkedIn post support imagery
- blog/article header reuse
- future curriculum-reform visuals

## Core Image Concept

The image should communicate an educational shift in center of gravity.

The left side should represent traditional software education centered on app construction, coding exercises, and isolated build tasks.

The right side should represent the emerging educational focus: architecture, systems thinking, integration, data flow, APIs, and AI-governed reasoning.

The image should visually suggest that basic app building is no longer enough as the primary educational endpoint.

## Prompt Used

```text
Professional editorial-style LinkedIn/blog header graphic, 16:9 landscape. Split-screen composition. Left side shows traditional software education centered on app construction: code editor, simple UI mockups, student building a basic app, isolated coding exercises, classroom/project feel. Right side shows the future educational focus: architecture diagrams, software layers, APIs, data models, integration flows, system boundaries, thoughtful AI-assisted engineering, clean systems reasoning. Visual message is that software education is moving beyond basic app construction toward architecture and systems thinking. Modern premium business-technology aesthetic, clean layout, academic-professional tone, charcoal, white, muted blue and warm neutral accents. Add elegant readable overlay title: "Why Software Education Must Move Beyond App Construction". Smaller subtitle: "As AI makes basic app creation easier, education must move upward." No robots, no sci-fi AI brains, no cyberpunk, no stock-photo clichés, no clutter.
```

## Design Intent

The image should support the article’s core thesis:

software education remains essential, but its value is shifting upward from basic application assembly toward architectural, systemic, and integrative reasoning.

## Style Guardrails

Avoid:

- robots
- glowing AI heads
- exaggerated futuristic visuals
- cliché hacker imagery
- decorative clutter

Prefer:

- editorial clarity
- professional thought-leadership tone
- conceptual sharpness
- modern but restrained composition
