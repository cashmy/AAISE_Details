# AI Image Prompt Record

## Purpose

This artifact records the image concept and prompt for:

- `AI Didn't Break Technical Interviews. It Exposed the Broken Ones.`

It is intended for:

- LinkedIn support imagery
- blog/article header reuse
- future visuals related to AI, technical hiring, assessment design, and
  developer evaluation

## Core Image Concept

The image should communicate that AI did not create the weakness in traditional
technical interviews. It revealed a pre-existing mismatch between artificial
logic-memory tests and the real competencies needed in modern software work.

The visual should contrast:

- an outdated, constrained technical interview built around isolated code recall
- a modern assessment environment focused on problem framing, validation,
  debugging, explanation, and responsible AI/tool use

The image should avoid generic AI imagery and should not imply that candidates
are cheating. The sharper idea is that the assessment model itself is being
exposed.

## Prompt Used

```text
Professional editorial-style LinkedIn/blog header graphic, 16:9 landscape. Split-screen composition. Left side shows an outdated technical interview scene: a stark whiteboard or locked-down coding test with a narrow puzzle, stopwatch pressure, and isolated memory-based logic recall. It should feel rigid, artificial, and outdated, but not cartoonish. Right side shows a modern technical assessment workspace: code editor, AI assistant panel, test results, debugging trace, requirement notes, and architecture/validation checklist, representing accountable tool-governed software work. Visual message: AI did not break technical interviews; it exposed weak assessment design. Premium business-technology aesthetic, clean modern editorial composition, intelligent and serious tone, charcoal, white, muted blue, and subtle amber warning accents. Add elegant readable overlay title: "AI Didn't Break Technical Interviews." Smaller subtitle: "It exposed the broken ones." No robots, no cyberpunk, no glowing AI brain, no hacker cliché, no stock-photo look, no clutter.
```

## Design Intent

The image should support the article's central thesis:

AI is not the fundamental problem in technical interviewing. The problem is that
many interviews still overvalue isolated logic-memory performance instead of
testing the modern developer's ability to frame problems, use tools
transparently, validate output, debug failures, and preserve responsibility.

## Suggested Variants

### Variant 1: LinkedIn Graphic

- preserve the title and subtitle
- optimize readability in feed
- make the contrast between old and new assessment models clear

### Variant 2: Blog Header

- keep the split-screen contrast
- reduce subtitle if needed
- allow more negative space for publication layout

### Variant 3: Assessment Validity Graphic

- remove the candidate/interview scene
- emphasize a broken assessment instrument being replaced by evidence of
  authentic technical judgment

## Style Guardrails

Avoid:

- robots
- glowing AI heads
- neon cyberpunk visuals
- cliché hacker imagery
- accusation-focused cheating imagery
- decorative clutter

Prefer:

- editorial clarity
- serious professional tone
- conceptual sharpness
- modern but restrained visual language
- clear contrast between brittle assessment and authentic technical work
