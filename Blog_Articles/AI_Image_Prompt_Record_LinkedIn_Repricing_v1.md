# AI Image Prompt Record

## Purpose

This artifact records the concept and prompt used for the LinkedIn-support image related to the article:

- `AI Is Not Replacing Software Expertise. It Is Repricing It.`
- `The Real Shift Is Not Code Generation. It Is Architectural Gravity.`

It is intended as a reusable visual reference for:

- LinkedIn post images
- blog/article header images
- future image variants for RBA-related writing

## Core Image Concept

The image should communicate a contrast between:

- easy AI-generated app creation
- deeper architectural reasoning required for real software systems

The visual should avoid generic AI imagery and instead emphasize the shift in value from low-complexity implementation toward architecture, systems thinking, boundaries, governance, and integration.

## Prompt Used

```text
Professional LinkedIn thought-leadership graphic, 16:9 landscape. Split-screen composition. Left side shows an AI app-builder interface generating a clean task-management app from a simple prompt, representing easy app generation. Right side shows a refined architectural systems view with layers, contracts, APIs, governance, workflows, and integration boundaries, representing deeper software expertise. Clean modern editorial style, minimal but intellectually sharp, premium business-technology aesthetic, charcoal, white, and muted blue palette. Add elegant readable overlay text: "AI Is Not Replacing Software Expertise. It Is Repricing It." Smaller subtitle beneath: "The real shift is not code generation. It is architectural gravity." No robots, no humanoid AI, no cyberpunk, no stock-photo look, no clutter.
```

## Design Intent

The image is meant to support a thesis:

AI is compressing the value of basic app scaffolding and low-complexity implementation, while increasing the relative value of architecture, systems reasoning, integration, and governed judgment.

## Suggested Variant Directions

### Variant 1: LinkedIn Header

- keep the split-screen format
- preserve both title and subtitle
- optimize text readability in-feed

### Variant 2: Blog Header

- same conceptual split
- reduce on-image text
- possibly retain only the main title

### Variant 3: Architectural Gravity Concept

- emphasize layered software stack
- visually compress lower layers
- visually emphasize upper-layer architecture and system design
- use little or no UI mockup

## Style Guardrails

Avoid:

- robots
- glowing AI brains
- neon cyberpunk visuals
- cliché code wallpaper
- overbusy diagrams
- gimmicky startup aesthetics

Prefer:

- modern editorial clarity
- professional business-technology tone
- conceptual sharpness
- minimal but intentional composition
- visual seriousness appropriate for thought leadership
