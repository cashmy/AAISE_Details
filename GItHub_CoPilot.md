# GitHub Copilot Pro Access for Students via GitHub Education

## Best Path: GitHub Education Student Verification (Free Copilot Pro Access)

Verified students through GitHub Education get **free access to GitHub Copilot's premium features** (equivalent to Copilot Pro). This is the most direct route — no financial aid processing needed.

---

## What Your Students Need to Do

1. **Create a GitHub personal account** (if they don't have one already).
2. **Navigate to** [github.com/settings/education/benefits](https://github.com/settings/education/benefits).
3. **Click "Start an application"** and complete the student verification process.
4. **Provide proof of enrollment**, such as:
   - A school ID with current enrollment date
   - Class schedule
   - Transcript
   - Enrollment verification letter
5. Once verified, they can activate **Copilot Student** from their Education benefits page.

📖 Full student guide: [Apply to GitHub Education as a student](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student)  
📖 Enabling Copilot: [Access GitHub Copilot for free as a student](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students)

---

## Important Notes for Your Program

- **SWTC must grant degrees, diplomas, or certificates** — which it sounds like it does, so students should qualify.
- Students need to prove **current enrollment status** — if SWTC does not issue academic email addresses, students can submit official documentation (school webpage or a letter on school letterhead) instead.
- If SWTC's email domain isn't recognized by GitHub, contact [GitHub Education Support](https://support.github.com/contact/education) with the school's name, website URL, and email domain.
- GitHub **reevaluates eligibility monthly**, so students need to maintain active enrollment.

---

## Optional: GitHub Campus Program (School-Wide)

If SWTC wants a more formal partnership, you (or a school administrator like a CTO/CIO, Dean, or Department Chair) can apply for the **[GitHub Campus Program](https://education.github.com/schools)**, which gives the whole school free access to GitHub Enterprise Cloud/Server. This is a school-level commitment, not individual student applications.

---

## Recommended Action

Direct each student to [github.com/settings/education/benefits](https://github.com/settings/education/benefits) to apply individually. The student verification route is the simplest and fastest path to free Copilot access.
