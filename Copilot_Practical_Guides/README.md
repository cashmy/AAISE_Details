# Copilot Practical Guides

Reusable student-facing guidance for GitHub Copilot surfaces.

## Purpose

These artifacts help students understand when to use VS Code integrated
Copilot, when to consider the GitHub Copilot app, and how to preserve ownership
when using agentic coding tools.

The Copilot app is treated as a later-program tool, not an early-program
shortcut. Beginning students should usually stay close to their code in the
editor unless an instructor explicitly allows a different workflow.

## Artifacts

- `Copilot_App_vs_VS_Code_Copilot_Student_Guide.md`
  - Plain-language comparison of VS Code Copilot and the GitHub Copilot app.
- `Copilot_App_Practical_Workflow_Guide.md`
  - Beginner-safe workflow for using the Copilot app later in the program.
- `Copilot_Permission_Gate_Prompts.md`
  - Reusable prompts that require inspect, summarize, ask, and wait behavior.
- `Copilot_App_RBA_Intro.md`
  - Light introduction to how the Copilot app can support RBA-style work later.

## Scope Boundary

These guides do not replace:

- course AI policy
- assignment-specific AI rules
- instructor permission
- student explanation and testing responsibilities

When in doubt, students should use the less automated tool and ask the
instructor before allowing AI to edit or generate substantial code.
