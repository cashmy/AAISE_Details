# 🔹 Now — CDP Step 4: Competency Framework (CF-01)

---

## 📘 HTML, CSS & JavaScript — Competencies

---

## **1. Structure web content using HTML**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Create structured web pages using semantic HTML elements
* Organize content logically using headings, paragraphs, and lists
* Link pages and resources appropriately
* Build multi-page website structures

---

### Learning Objectives

* Define HTML structure and purpose
* Identify common HTML elements
* Explain semantic markup

---

---

## **2. Design and style web pages using CSS**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Apply CSS to control layout, spacing, and visual design
* Use selectors, classes, and IDs effectively
* Create responsive and visually consistent layouts
* Adjust design to improve usability and readability

---

### Learning Objectives

* Define CSS styling principles
* Explain layout concepts (box model, positioning)
* Identify responsive design basics

---

---

## **3. Implement interactive behavior using JavaScript**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Write basic JavaScript programs using variables, conditionals, and functions
* Apply JavaScript to create interactive behaviors in web pages
* Respond to user input and events
* Connect program logic to visible outcomes

---

### Learning Objectives

* Define JavaScript as a programming language
* Explain variables, functions, and control flow
* Describe how JavaScript enables interactivity

---

---

## **4. Debug and evaluate web applications using progressive techniques**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Identify and correct layout and styling issues
* Use console logging to trace program behavior
* Utilize browser tools to inspect and troubleshoot web pages
* Interpret and resolve common errors

---

### Learning Objectives

* Define debugging and troubleshooting
* Identify common HTML, CSS, and JavaScript errors
* Explain debugging techniques

---

---

## **5. Develop web solutions using structured thinking and appropriate tools**

### Assessment Strategies

* Project assignments and quiz

### Criteria

Learners will be successful when they are able to:

* Plan and build web pages based on defined requirements
* Apply structured problem-solving to design and implementation
* Use AI tools to assist in development when appropriate
* Evaluate and refine solutions for clarity, usability, and correctness

---

### Learning Objectives

* Describe structured development approaches
* Identify when and how to use AI tools
* Explain iterative improvement of web solutions

---
