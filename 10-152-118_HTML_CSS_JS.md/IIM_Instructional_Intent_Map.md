# 🧭 INSTRUCTIONAL INTENT MAP (IIM) — HTML, CSS, JS

---

# 🔹 PHASE 1 — FOUNDATIONS (Weeks 1–3)

**Mode:** Compartmentalized (safety, clarity, alignment with textbooks)

---

## 🗓 Week 1 — HTML: “Something Exists”

### Monday (Lecture)

* Establish web page as a **structured document**, not “code”
* Introduce HTML as *meaning*, not appearance
* Show full page lifecycle (file → browser → render)

### Tuesday (Lab — Guided)

* Build first multi-page site (very simple)
* Reinforce structure: headings, paragraphs, links

### Wednesday (Video)

* Deepen: semantic elements vs generic tags
* Show “bad vs good structure” examples

### Thursday (Lab — Light Application)

* Expand site (add page, improve structure)
* Introduce intentional organization (folders, naming)

---

## 🗓 Week 2 — CSS: “I Can Control Appearance”

### Monday (Lecture)

* Introduce CSS as **separate layer**
* Emphasize: HTML ≠ styling
* Basic selectors, classes, IDs

### Tuesday (Lab — Guided)

* Apply styling to Week 1 project
* Typography, spacing, colors

### Wednesday (Video)

* Specificity basics
* Common mistakes (overwriting styles, confusion)

### Thursday (Lab — Application)

* Improve visual consistency
* Introduce design intention (readability, spacing)

---

## 🗓 Week 3 — Layout: “Control Space”

### Monday (Lecture)

* Box model as **mental model**
* Flexbox introduction
* Layout ≠ positioning hacks

### Tuesday (Lab — Guided)

* Convert page into structured layout
* Use Flexbox for alignment

### Wednesday (Video)

* Responsive thinking (media queries intro)
* Show layout breakpoints

### Thursday (Lab — Application)

* Redesign layout for multiple screen sizes
* Introduce *iteration mindset*

---

# 🔑 Phase Shift Coming:

Students feel confident → about to be disrupted (intentionally)
