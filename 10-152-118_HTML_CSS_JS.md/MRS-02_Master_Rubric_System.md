# 🧱 PART 2 — TECHNICAL COMPETENCIES

(Primary grading categories — aligned to WIDS)

---

## 🔹 1. Structure (HTML)

**Evidence:** Semantic structure, organization, navigation

| Level                     | Description                                                                     |
| ------------------------- | ------------------------------------------------------------------------------- |
| **4 — Exceeds**           | Clean, semantic HTML; logical structure across pages; proper linking/navigation |
| **3 — Meets**             | Mostly correct structure with minor issues                                      |
| **2 — Developing**        | Inconsistent or unclear structure                                               |
| **1 — Needs Improvement** | Broken or incorrect structure                                                   |

---

## 🔹 2. Styling & Layout (CSS)

**Evidence:** Layout, spacing, typography, responsiveness

| Level                     | Description                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------ |
| **4 — Exceeds**           | Intentional spacing, typography, and layout; visually clear; consistent across pages |
| **3 — Meets**             | Functional styling with minor inconsistencies                                        |
| **2 — Developing**        | Basic styling, limited layout control                                                |
| **1 — Needs Improvement** | Poor readability or layout issues                                                    |

---

## 🔹 3. Interactivity (JavaScript)

**Evidence:** Functionality, events, logic

| Level                     | Description                                                        |
| ------------------------- | ------------------------------------------------------------------ |
| **4 — Exceeds**           | Correct use of logic and events; behavior matches intended outcome |
| **3 — Meets**             | Basic interactivity works                                          |
| **2 — Developing**        | Partial or inconsistent behavior                                   |
| **1 — Needs Improvement** | Broken or missing functionality                                    |

---

## 🔹 4. Debugging & Problem Solving

**Evidence:** Error identification, fixes, use of tools

| Level                     | Description                                                                      |
| ------------------------- | -------------------------------------------------------------------------------- |
| **4 — Exceeds**           | Systematically identifies issues; uses tools effectively; clearly explains fixes |
| **3 — Meets**             | Finds and fixes most issues                                                      |
| **2 — Developing**        | Attempts fixes with limited success                                              |
| **1 — Needs Improvement** | Unable to identify or resolve issues                                             |

---

## 🔹 5. Structured Development

**Evidence:** Code organization, planning, iteration

| Level                     | Description                                                                    |
| ------------------------- | ------------------------------------------------------------------------------ |
| **4 — Exceeds**           | Well-organized code; clear structure and reuse; iterative improvements evident |
| **3 — Meets**             | Generally organized with minor issues                                          |
| **2 — Developing**        | Some organization but inconsistent                                             |
| **1 — Needs Improvement** | Disorganized or difficult to follow                                            |
