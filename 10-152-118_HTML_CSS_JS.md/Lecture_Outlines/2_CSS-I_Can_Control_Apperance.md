# 🧭 **WEEK 2 — MONDAY LECTURE OUTLINE**

**Title:** *Week 2 — Styling: Controlling Appearance*

---

## **1. Opening Frame**

> “Last week, you made something that works.
> This week, you will make it readable and visually organized.”

* Shift from *existence* → *experience*
* Still grounded—no “design perfection” yet

---

## **2. Course Positioning**

> “You now have structure.
> This week, you add a new layer—style.”

* Reinforce separation:

  * HTML = structure
  * CSS = appearance

👉 Critical:

> “We are not changing what the page *is*—only how it *looks*.”

---

## **3. Core Concepts**

* What CSS is (styling layer)
* Linking CSS to HTML (external file)
* Basic selectors:

  * element
  * class (introduce lightly)
* The box model (margin, padding — concept level)
* Readability principles:

  * spacing
  * contrast
  * hierarchy

---

## **4. Demonstration / Example Layer**

* Show:

  * Week 1 site (unstyled)
  * same site with basic CSS

👉 Emphasize:

* readability improvement

* spacing changes impact

* Show:

  * inline vs external CSS (and why external wins)

---

## **5. Common Mistakes / Watch-Fors**

* Using inline styles instead of CSS file
* Random colors (no readability consideration)
* Over-styling too early
* Breaking structure while styling

---

## **6. Tuesday Lab Bridge**

> “In lab, your goal is not to make it look amazing.
> Your goal is to make it readable and consistent.”

Focus them on:

* linking CSS correctly
* improving spacing
* basic visual consistency

---

## **7. Closing Frame**

> “If your site is easier to read and navigate—you succeeded.”

---

# 🧭 **WEEK 2 — WEDNESDAY CONCEPT FOCUS**

**Title:** *Week 2 — Readability, Spacing, and Consistency*

---

## **1. Re-Anchor the Week**

> “This week is about making your structure usable.”

Not pretty.
Usable.

---

## **2. Deep Concept Focus**

* Readability as a primary goal

* Spacing controls how content is understood

* Visual hierarchy:

  * what stands out
  * what supports

* Consistency across pages

---

## **3. Common Confusion Patterns**

* “It looks worse after styling” → over-styling
* “Why does spacing feel off?” → misunderstanding margin/padding
* “Each page looks different” → lack of shared styles

---

## **4. Thinking Tools / Heuristics**

* “Can I read this easily?”
* “Do similar things look the same?”
* “Is there space between sections?”
* “Does anything feel crowded?”

---

## **5. Thursday Refinement Bridge**

> “For Thursday, focus on consistency across pages.”

Specifically:

* same styles applied everywhere
* improved spacing
* cleaner visual hierarchy

---

## **6. Closing Reinforcement**

> “Good styling is not about decoration—it’s about clarity.”

---
