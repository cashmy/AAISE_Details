# 🧭 ASSIGNMENT 15 — FORMS & CAPSTONE IDEA PROPOSAL

**Week 15 — “Input & Idea Selection”**

---

## 🔹 Context

So far, your applications have:

* displayed information
* responded to interaction
* managed state and behavior

This week introduces **user input as structured data**.

At the same time, you will begin selecting your **capstone project idea**.

---

## 🔹 Objective

* Learn how to collect and handle user input using forms
* Propose a capstone idea for approval

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Add a form to your application.

---

### 🔹 Requirements

Create a form that includes:

* at least **2–3 input fields**, such as:

  * text input
  * selection (dropdown or radio)
  * checkbox

* a **submit action**

Your form must:

* capture user input
* display or use that input in your application

---

### 🔹 Focus

* collecting input
* handling user-provided data
* connecting input to behavior

---

### 🔹 Expectation

Input handling may introduce new edge cases.

That is expected.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* Forms as a way to collect structured input
* The relationship between input, state, and behavior
* Validating and handling user-provided data
* Designing inputs that are clear and usable
* How user input drives application functionality
