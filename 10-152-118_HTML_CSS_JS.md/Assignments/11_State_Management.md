# 🧭 ASSIGNMENT 11 — STATE MANAGEMENT

**Week 11 — “Things Persist”**

---

## 🔹 Context

Last week, your application began working with external or structured data.

This week, you will focus on how your application:

* keeps track of information
* updates that information
* maintains consistency over time

---

## 🔹 Objective

Implement basic state management by:

* storing values
* updating them based on interaction
* reflecting those changes in the UI

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Add state to your application.

---

### 🔹 Requirements

Your application must:

* store at least **one piece of data** (state), such as:

  * a counter
  * a selected item
  * user input

* allow the user to:

  * change that value
  * see the result update on the page

---

### 🔹 Examples (for guidance)

* a counter that increases/decreases
* a selection that changes displayed content
* input that updates a message

---

### 🔹 Focus

* tracking values
* updating state
* connecting state to display

---

### 🔹 Expectation

Understanding state may feel subtle at first.

That is normal.
