# 🧭 ASSIGNMENT 7 — STRUCTURED JAVASCRIPT

**Week 7 — “From Working to Clean”**

---

## 🔹 Context

You can now:

* build interactive pages
* debug issues when they occur

This week focuses on improving **how your code is written**.

Working code is important—but **clear, organized code is better**.

---

## 🔹 Objective

Improve your JavaScript by:

* organizing logic into functions
* improving readability
* reducing repetition

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Refactor your existing JavaScript code.

---

### 🔹 Requirements

* Use **functions** to organize your code

* Reduce repeated code where possible

* Ensure each function has a clear purpose

* Your code should include:

  * at least **2–3 functions**
  * meaningful variable names

---

### 🔹 Focus

* grouping related logic
* separating responsibilities
* improving clarity

---

### 🔹 Expectation

Refactoring may feel slower than writing new code.

That is normal—and intentional.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* Why structure matters in programming
* Functions as building blocks of behavior
* Separating concerns (what vs how)
* Readability vs functionality
* Common signs of poorly structured code
