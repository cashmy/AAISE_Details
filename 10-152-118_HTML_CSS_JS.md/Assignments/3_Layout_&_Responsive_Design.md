# 🧭 ASSIGNMENT 3 — LAYOUT & RESPONSIVE DESIGN

**Week 3 — “Control Space”**

---

## 🔹 Context

You now have:

* structured content (HTML)
* styled content (CSS)

This week, you will take control of **layout and space**.

You will learn how to organize content on the page and adjust it for different screen sizes.

---

## 🔹 Objective

Improve your existing website by:

* organizing content using layout techniques
* applying responsive design principles
* ensuring your site works across different screen sizes

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Apply layout techniques to your existing pages.

---

### 🔹 Requirements

* Use **Flexbox** (required) to:

  * organize at least one section of your page
  * align or distribute elements intentionally

* Improve layout for:

  * navigation
  * main content sections

* Ensure:

  * content is not stacked awkwardly
  * spacing is intentional

---

### 🔹 Focus

* controlling placement
* organizing sections
* understanding layout behavior

---

### 🔹 Expectation

Layout may feel confusing at first.
That is normal.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* How layout decisions affect readability and usability
* Flexbox as a system for organizing space and alignment
* The difference between stacking content and designing layout
* Introduction to responsive thinking and screen size variation
* Why responsive design matters for real-world applications

---

# 🔧 ITERATION 2 — REFINE (Thursday Lab)

### 🔹 Task

Improve layout and introduce responsiveness.

---

### 🔹 Requirements

* Apply at least **one media query**

  * adjust layout for smaller screens

* Improve:

  * spacing consistency
  * alignment of elements
  * readability across screen sizes

* Ensure:

  * navigation remains usable
  * layout adapts (not just shrinks)

---

### 🔹 Focus

* adaptability
* readability
* intentional layout decisions

---

# 📦 FINAL SUBMISSION

Submit your updated website including:

* HTML files
* CSS file

---

### 🔹 Submission Requirements

* Flexbox must be used in layout
* At least one media query must be implemented
* All pages must render correctly

---

# 🔥 Instructor Notes (For You)

This is the first **cognitive strain point**.

Students often:

* struggle with Flexbox behavior
* become frustrated with alignment
* misunderstand responsiveness

Your role:

* normalize confusion
* reinforce iteration
* keep focus on *progress*, not perfection
