# 🧭 ASSIGNMENT 4 — INTRODUCTION TO JAVASCRIPT

**Week 4 — “This Is Programming”**

---

## 🔹 Context

So far, you have learned how to:

* build structure (HTML)
* control appearance (CSS)
* organize layout

This week, you will begin working with **JavaScript**.

JavaScript is different.

Instead of describing what something *is*, you will now control how something *behaves*.

---

## 🔹 Objective

Learn the fundamentals of programming using JavaScript:

* variables
* conditions
* functions

This week focuses on understanding how programs work—not yet connecting them to your web pages.

---

# 🧱 ITERATION 1 — BUILD (Tuesday Lab)

### 🔹 Task

Write and run basic JavaScript programs.

---

### 🔹 Requirements

Create a JavaScript file that includes:

* at least **2 variables**
* at least **1 conditional statement** (`if / else`)
* at least **1 function**

Your program should:

* perform a simple calculation or decision
* output results using `console.log()`

---

### 🔹 Focus

* understanding syntax
* following logic step-by-step
* seeing how values change

---

### 🔹 Expectation

This will feel different—and possibly difficult.

That is normal.

---

# 🧠 CONCEPT FOCUS (Wednesday)

* What a program is and how it executes step-by-step
* Variables as stored values
* Conditions as decision points
* Functions as reusable logic
* Common beginner mistakes in programming
