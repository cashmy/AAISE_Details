# AI Prompting Basics

Reusable optional lecture module for 10-152 courses.

## Purpose

This folder contains a course-agnostic recorded lecture source on basic prompt
engineering for students. It is intended to support Python Programming
Foundations, Web Development Foundations, and Algorithmic Problem Solving
without replacing course-specific AI-use policies.

## Artifacts

- `AI_Prompting_Basics_Lecture_Deck_Source.md`
  - Student-facing slide source and instructor notes.
- `AI_Prompting_Basics_Image_Prompts.md`
  - Browser-based ChatGPT image-generation prompts for slide visuals.

## Design Intent

The lecture uses a practical modern prompt pattern:

- Context
- Attempt
- Allowed help
- Constraints
- Clarifying questions
- Output format

It deliberately avoids the full RBA workflow. The focus is beginner prompting
for learning support, debugging explanation, code structure explanation,
reading support, and permission-gated use of code-editing AI tools.
